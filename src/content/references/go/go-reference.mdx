## Core Syntax & Idioms

| Concept | Example |
| :--- | :--- |
| Short declaration | `name := "DevPath"` |
| Slice append | `items = append(items, "Go")` |
| Map comma-ok | `val, ok := m["key"]` |
| Error wrapping | `fmt.Errorf("load user: %w", err)` |
| Goroutine + WaitGroup | `wg.Add(1); go func() { defer wg.Done(); work() }()` |
| Buffered channel | `ch := make(chan int, 16)` |
| Context timeout | `ctx, cancel := context.WithTimeout(ctx, 2*time.Second)` |
| Race detector | `go test -race ./...` |
