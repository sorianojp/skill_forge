## Indexing & Query Performance

| Feature | Syntax |
| :--- | :--- |
| Composite index | `CREATE INDEX idx_orders_user_date ON orders (user_id, created_at DESC);` |
| Partial index | `CREATE INDEX idx_jobs_pending ON jobs (priority) WHERE status = 'pending';` |
| JSONB GIN index | `CREATE INDEX idx_events_payload ON events USING GIN (payload);` |
| Concurrent build | `CREATE INDEX CONCURRENTLY idx_email ON users (LOWER(email));` |
| Query plan | `EXPLAIN (ANALYZE, BUFFERS) SELECT ...;` |
| Window rank | `ROW_NUMBER() OVER (PARTITION BY dept ORDER BY salary DESC)` |
| Row lock | `SELECT * FROM wallets WHERE id = $1 FOR UPDATE;` |
