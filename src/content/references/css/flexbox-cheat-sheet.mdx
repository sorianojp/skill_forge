syntax: "display: flex; justify-content: ...; align-items: ...; gap: ...;"

browserSupport: "Baseline Widely Available"
---

| Property | Values | Effect |
| :--- | :--- | :--- |
| `flex-direction` | `row` \| `column` | Sets the main axis direction |
| `justify-content` | `flex-start` \| `center` \| `space-between` \| `space-evenly` | Distributes items along the main axis |
| `align-items` | `stretch` \| `center` \| `flex-start` \| `baseline` | Aligns items along the cross axis |
| `flex-wrap` | `nowrap` \| `wrap` | Allows items to wrap onto multiple lines |
| `gap` | `<length>` | Space between flex items |
