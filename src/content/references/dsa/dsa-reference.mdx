## Pattern Cheat Sheet

| Problem Clue | Go-To Pattern | Typical Time |
| :--- | :--- | :--- |
| Find complement / duplicates | Hash Map / Hash Set | `O(n)` |
| Sorted array pair or palindrome | Two Pointers | `O(n)` |
| Nested brackets / undo history | LIFO Stack | `O(n)` |
| Sorted search or monotonic answer | Binary Search | `O(log n)` |
| Shortest unweighted path / levels | BFS (Queue) | `O(V + E)` |
| Overlapping recursive subproblems | Dynamic Programming | `O(n)` – `O(n^2)` |
