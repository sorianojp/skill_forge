## Document & Metadata

| Tag | Description |
| :--- | :--- |
| `<!doctype html>` | Declares HTML5 standards mode |
| `<html lang="en">` | Root document element with language code |
| `<head>` | Container for metadata, title, stylesheets, and scripts |
| `<meta>` | Charset, viewport, SEO description, Open Graph tags |
| `<title>` | Browser tab & search-result document title |
| `<link>` | Links external stylesheets, favicons, canonical URLs |

## Landmarks & Sectioning

| Tag | Description |
| :--- | :--- |
| `<header>` | Page or section header / banner |
| `<nav>` | Primary or secondary navigation links |
| `<main>` | Dominant, unique content of the page (one per page) |
| `<article>` | Self-contained composition (post, lesson, card) |
| `<section>` | Thematic grouping with a heading |
| `<aside>` | Sidebar, callout, or complementary content |
| `<footer>` | Closing metadata, copyright, secondary links |

## Text & Inline Semantics

| Tag | Description |
| :--- | :--- |
| `<h1>` – `<h6>` | Hierarchical section headings |
| `<p>` | Paragraph of text |
| `<a>` | Hyperlink (`href`, `target`, `rel`) |
| `<strong>` / `<em>` | Strong importance / verbal emphasis |
| `<code>` / `<pre>` / `<kbd>` | Inline code, preformatted block, keyboard input |
| `<time>` / `<mark>` / `<abbr>` | Machine-readable date, highlighted text, abbreviation |
| `<blockquote>` | Extended quotation |

## Lists & Tables

| Tag | Description |
| :--- | :--- |
| `<ul>` / `<ol>` / `<li>` | Unordered list, ordered list, and list items |
| `<dl>` / `<dt>` / `<dd>` | Description list, term, and definition |
| `<table>` / `<caption>` | Tabular data container and accessible title |
| `<thead>` / `<tbody>` / `<tfoot>` | Table header, body, and footer row groups |
| `<tr>` / `<th scope>` / `<td>` | Table row, header cell, and data cell |

## Media, Graphics & Embeds

| Tag | Description |
| :--- | :--- |
| `<img>` | Image (`src`, `alt`, `width`, `height`, `loading="lazy"`) |
| `<picture>` / `<source>` | Responsive art-directed or next-gen image formats |
| `<figure>` / `<figcaption>` | Self-contained media with an associated caption |
| `<audio>` / `<video>` / `<track>` | Native media playback and WebVTT captions |
| `<svg>` / `<canvas>` | Scalable vector graphics / pixel-based JS drawing surface |
| `<iframe>` | Sandboxed embedded document (`title`, `sandbox`) |

## Forms & Interactive Elements

| Tag | Description |
| :--- | :--- |
| `<form>` | User input form (`action`, `method="dialog"`) |
| `<label>` / `<input>` / `<textarea>` | Accessible form controls |
| `<fieldset>` / `<legend>` | Groups related form controls with a caption |
| `<select>` / `<option>` / `<datalist>` | Dropdown menus and native autocomplete suggestions |
| `<button>` | Clickable action button (`type="button" | "submit"`) |
| `<details>` / `<summary>` | Native zero-JS collapsible accordion / disclosure |
| `<dialog>` | Native top-layer modal (`showModal()`) or non-modal dialog |
| `<template>` / `<slot>` | Inert HTML templates and Shadow DOM content slots |
