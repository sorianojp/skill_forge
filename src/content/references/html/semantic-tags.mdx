---

| Element | Purpose | Rule of Thumb |
| :--- | :--- | :--- |
| `<header>` | Introductory content or site banner | Usually holds logo and primary nav |
| `<nav>` | Major navigation links | Add `aria-label` when using multiple `<nav>` blocks |
| `<main>` | Dominant unique page content | Only **one** visible `<main>` per page |
| `<article>` | Self-contained composition | Blog post, lesson, or comment card |
| `<aside>` | Tangentially related content | Sidebar TOC, callouts, related links |
| `<footer>` | Closing metadata | Copyright, secondary links, author info |
