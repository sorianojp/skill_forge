## Everyday Docker CLI

| Command | Purpose | Example |
| :--- | :--- | :--- |
| `docker build -t` | Build image from Dockerfile | `docker build -t app:1.0 .` |
| `docker run -d -p` | Run detached container with port map | `docker run -d -p 8080:80 nginx` |
| `docker logs -f` | Stream container stdout/stderr | `docker logs -f web` |
| `docker exec -it` | Open shell inside running container | `docker exec -it web sh` |
| `docker compose up -d` | Start multi-container stack | `docker compose up -d --build` |
