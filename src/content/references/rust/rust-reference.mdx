## Core Rust & Cargo Cheat Sheet

| Concept | Syntax / Command |
| :--- | :--- |
| Mutable binding | `let mut count = 0;` |
| Shared / exclusive borrow | `&value` (many) vs `&mut value` (one) |
| Error propagation | `let n: i32 = s.parse()?;` |
| Safe indexing | `items.get(i)` returns `Option<&T>` |
| Thread-safe shared state | `Arc<Mutex<T>>` |
| Lint idioms | `cargo clippy` |
| Run unit tests | `cargo test` |
| Release binary | `cargo build --release` |
