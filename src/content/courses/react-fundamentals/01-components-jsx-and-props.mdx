**React** treats your UI as a pure function of your data: `UI = Component(props, state)`. Instead of manually hunting down DOM elements with `document.querySelector`, you declare *what* the UI should look like for the current state, and React efficiently updates the DOM.

<Callout type="tip" title="Props Are Read-Only">
  Never mutate a prop object inside a child component. Data flows downward from parent to child, and children notify parents by calling callback props like <code>onSelect(id)</code>.
</Callout>
