When rendering lists in React (`items.map(item => <Row key={item.id} ... />)`), the **`key`** prop lets React match each item across renders so inputs, animations, and local state stay attached to the right row.

<Callout type="warning" title="Avoid Array Index Keys on Dynamic Lists">
  Using <code>key=&#123;index&#125;</code> breaks when items are inserted, deleted, or sorted. Always use a stable unique ID like <code>item.id</code> or <code>item.slug</code>.
</Callout>

## Live Derived List Demo

<ReactPlayground
  client:visible
  title="Live Keyed List & Derived Filter (JSX)"
  code={`const TRACKS = [
  { slug: 'ts', title: 'TypeScript 5' },
  { slug: 'react', title: 'React 19' },
  { slug: 'node', title: 'Node.js 20' },
  { slug: 'docker', title: 'Docker & Compose' },
];

function App() {
  const [query, setQuery] = useState('');
  const visible = TRACKS.filter((t) =>
    t.title.toLowerCase().includes(query.toLowerCase())
  );

  return (
    <div>
      <input
        value={query}
        onChange={(e) => setQuery(e.target.value)}
        placeholder="Filter tracks..."
        style={{ padding: '8px 12px', borderRadius: 10, border: '1px solid #cbd5e1', width: '100%' }}
      />
      <ul style={{ marginTop: 10, paddingLeft: 18 }}>
        {visible.map((t) => <li key={t.slug}>{t.title}</li>)}
      </ul>
    </div>
  );
}`}
/>
