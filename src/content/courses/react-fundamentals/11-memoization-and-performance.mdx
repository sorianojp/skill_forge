**`useMemo(() => compute(items), [items])`** caches the result of an expensive calculation (like filtering/sorting 20,000 rows) until its dependencies change. **`useCallback(fn, [deps])`** stabilizes a function reference passed to memoized children or effect dependencies.

<Callout type="tip" title="Profile First, Memoize Second">
  Wrapping trivial calculations in <code>useMemo</code> adds complexity and memory overhead without visible speedup. Measure with React DevTools Profiler first.
</Callout>

## Live Memoization Demo

<Playground
  client:visible
  title="Cache Hit vs. Cache Miss"
  defaultTab="js"
  showConsole={true}
  html={`<p>See how memoization skips recomputing when inputs do not change.</p>`}
  js={`let lastKey = null, lastVal = null;
function memoSort(nums) {
  const key = nums.join(",");
  if (key === lastKey) {
    console.log("-> Cache hit!");
    return lastVal;
  }
  console.log("-> Computing sort...");
  lastKey = key;
  lastVal = [...nums].sort((a, b) => a - b);
  return lastVal;
}

console.log(memoSort([9, 3, 7, 1]));
console.log(memoSort([9, 3, 7, 1]));`}
