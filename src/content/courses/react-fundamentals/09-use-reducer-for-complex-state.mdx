When a component has 4+ interconnected `useState` calls that change together (like a multi-step wizard, cart, or async form), **`useReducer`** centralizes every transition inside one pure function `(state, action) => newState`.

<Callout type="tip" title="Reducers Are Trivial to Unit Test">
  Because a reducer is a plain JavaScript function with zero React imports, you can test every edge case directly with <code>reducer(initialState, action)</code>.
</Callout>

## Live Reducer Playground

<Playground
  client:visible
  title="Pure Cart Reducer"
  defaultTab="js"
  showConsole={true}
  html={`<p>Check the console to see pure reducer transitions in action.</p>`}
  js={`function cartReducer(state, action) {
  switch (action.type) {
    case "add": return { items: [...state.items, action.name] };
    case "clear": return { items: [] };
    default: return state;
  }
}

let s = { items: [] };
s = cartReducer(s, { type: "add", name: "React Track" });
s = cartReducer(s, { type: "add", name: "Node Track" });
console.log("Cart:", s.items);
s = cartReducer(s, { type: "clear" });
console.log("After clear:", s.items);`}
/>
