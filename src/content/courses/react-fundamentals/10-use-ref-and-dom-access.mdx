**`useRef(initial)`** returns a persistent box `{ current: initial }` that survives across re-renders. Unlike `useState`, changing `ref.current` does **not** trigger a re-render, making it ideal for DOM element handles (`inputRef.current?.focus()`) and timer IDs.

<Callout type="warning" title="Do Not Use Refs for Rendered UI Data">
  If a value is displayed on screen in JSX, store it in <code>useState</code> so React re-renders when it changes. Use <code>useRef</code> only for non-visual values or DOM APIs.
</Callout>
