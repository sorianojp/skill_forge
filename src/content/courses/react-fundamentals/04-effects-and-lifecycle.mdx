**`useEffect`** synchronizes a React component with an **external system** (DOM event listeners, timers, WebSockets, or data fetching). Always return a **cleanup function** whenever you subscribe to a listener or start an interval so React cleans it up on unmount.

<Callout type="tip" title="You Might Not Need an Effect">
  Never use <code>useEffect</code> just to compute a derived value or handle a button click. Handle user actions inside event handlers, and compute derived values directly during render.
</Callout>

## Live Lifecycle Cleanup Demo

<Playground
  client:visible
  title="Effect Mount & Unmount Simulation"
  defaultTab="js"
  showConsole={true}
  html={`<p>Check the console to see how effect setup and cleanup pair together.</p>`}
  js={`function mountEffect(effectFn) {
  console.log("Component mounted");
  const cleanup = effectFn();
  return () => {
    console.log("Component unmounting...");
    if (cleanup) cleanup();
  };
}

const unmount = mountEffect(() => {
  console.log("-> Subscribed to keyboard shortcuts");
  return () => console.log("-> Removed keyboard listener cleanly");
});

unmount();`}
/>
