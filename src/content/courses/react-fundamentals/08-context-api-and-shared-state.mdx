**React Context** lets a parent component provide values (such as dark/light theme or the signed-in user) to any deeply nested descendant without threading props through every intermediate component.

<Callout type="warning" title="Do Not Put Fast-Changing State in One Giant Context">
  Every consumer of a Context re-renders when its value changes. Keep contexts focused (e.g., <code>AuthContext</code>, <code>ThemeContext</code>) rather than putting every form keystroke into one global provider.
</Callout>

## Live Context Simulation

<Playground
  client:visible
  title="Theme Provider Pattern"
  defaultTab="js"
  showConsole={true}
  html={`<button id="toggle" style="padding:8px 14px;border-radius:10px;border:0;background:#0f172a;color:#fff;cursor:pointer">Toggle Theme</button>
<p id="card" style="margin-top:10px;padding:12px;border-radius:10px"></p>`}
  js={`let theme = "light";
function render() {
  const card = document.getElementById("card");
  card.style.background = theme === "dark" ? "#0f172a" : "#f1f5f9";
  card.style.color = theme === "dark" ? "#f8fafc" : "#0f172a";
  card.textContent = "Consumed ThemeContext: " + theme;
}
document.getElementById("toggle").addEventListener("click", () => {
  theme = theme === "light" ? "dark" : "light";
  render();
});
render();`}
/>
