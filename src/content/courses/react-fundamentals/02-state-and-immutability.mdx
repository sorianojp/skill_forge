React detects state changes by comparing object references (`Object.is`). If you mutate an array in place (`items.push(x); setItems(items)`), React sees the exact same array reference and **skips re-rendering**. Always create a fresh copy: `setItems(prev => [...prev, x])`.

<Callout type="warning" title="Never Mutate State Directly">
  Use <code>[...items, newItem]</code> to append, <code>items.filter(...)</code> to remove, and <code>&#123; ...user, name: "New" &#125;</code> to update objects.
</Callout>

## Live Interactive State Demo

<Playground
  client:visible
  title="Immutable Counter & List State"
  defaultTab="js"
  showConsole={true}
  html={`<button id="inc" style="padding:8px 14px;border-radius:10px;border:0;background:#0284c7;color:#fff;font-weight:700;cursor:pointer">Add Lesson (+1)</button>
<p id="out" style="margin-top:12px;font-weight:700"></p>`}
  js={`let state = { completed: ["Lesson 1"] };

function setState(updater) {
  state = updater(state);
  document.getElementById("out").textContent =
    "Completed (" + state.completed.length + "): " + state.completed.join(", ");
}

document.getElementById("inc").addEventListener("click", () => {
  setState((prev) => ({
    ...prev,
    completed: [...prev.completed, "Lesson " + (prev.completed.length + 1)]
  }));
});

setState((s) => s);`}
/>
