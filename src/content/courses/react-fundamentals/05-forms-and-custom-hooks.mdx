A **custom hook** is simply a JavaScript function whose name starts with **`use`** (like `useDebounce` or `useLocalStorage`) and that calls built-in React hooks. Custom hooks let multiple components reuse stateful behavior cleanly without duplicating code.

<Callout type="warning" title="Rules of Hooks">
  Always call hooks at the <strong>top level</strong> of your React component or custom hook, never inside <code>if</code> conditions, loops, or nested callbacks.
</Callout>

<Playground
  client:visible
  title="Controlled Form Validation"
  defaultTab="js"
  showConsole={true}
  html={`<form id="f" style="display:flex;gap:8px">
  <input id="email" placeholder="you@dev.io" style="padding:8px 12px;border-radius:10px;border:1px solid #cbd5e1;flex:1" />

<p id="msg" style="margin-top:8px;font-size:13px"></p>`}
  js={`document.getElementById("f").addEventListener("submit", (e) => {
  e.preventDefault();
  const val = document.getElementById("email").value.trim();
  const ok = val.includes("@");
  document.getElementById("msg").textContent = ok
    ? "Valid email saved: " + val
    : "Please enter a valid email address.";
});`}
/>
