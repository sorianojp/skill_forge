## Overview

Master Next.js App Router folder-based routing, shared nested layouts, and persistent navigation shells.

Next.js App Router unifies server rendering, streaming, type-safe mutations, and edge-ready caching inside a single React + TypeScript codebase.

## Production Code Example

```tsx
// app/dashboard/layout.tsx
export default function DashboardLayout({ children }: { children: React.ReactNode }) {
  return (
    <div className="grid grid-cols-[240px_1fr] min-h-screen">
      <aside className="border-r p-4">Sidebar Nav</aside>
      <main className="p-6">{children}</main>
    </div>
  );
}
```

<Callout type="tip" title="Next.js Best Practice">
Keep Server Components as your default, validate every Server Action and Route Handler input on the server, and verify your production bundle size with `next build` before shipping.
</Callout>

## Key Takeaways

- **Map folder segments under app/ directly to URL routes**
- **Share persistent UI with layout.tsx without remounting on navigation**
- **Use route groups like (marketing) to organize folders without changing URLs**
