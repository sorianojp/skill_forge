## Overview

Handle form submissions and database writes securely using 'use server' actions, Zod validation, and revalidatePath.

Next.js App Router unifies server rendering, streaming, type-safe mutations, and edge-ready caching inside a single React + TypeScript codebase.

## Production Code Example

```tsx
// app/tasks/actions.ts
'use server';
import { revalidatePath } from 'next/cache';

export async function createTask(formData: FormData) {
  const title = String(formData.get('title') ?? '').trim();
  if (title.length < 3) throw new Error('Title too short');
  // await db.insert(tasks).values({ title });
  revalidatePath('/tasks');
}
```

<Callout type="tip" title="Next.js Best Practice">
Keep Server Components as your default, validate every Server Action and Route Handler input on the server, and verify your production bundle size with `next build` before shipping.
</Callout>

## Key Takeaways

- **Define server-only mutations with the 'use server' directive**
- **Validate every FormData input on the server before touching the DB**
- **Call revalidatePath() after mutations so UI refreshes automatically**
