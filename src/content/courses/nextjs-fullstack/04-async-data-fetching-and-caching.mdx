## Overview

Fetch data directly inside async Server Components and refresh stale data cleanly with revalidatePath and revalidateTag.

Next.js App Router unifies server rendering, streaming, type-safe mutations, and edge-ready caching inside a single React + TypeScript codebase.

## Production Code Example

```tsx
// app/courses/page.tsx
import { revalidateTag } from 'next/cache';

export async function CoursesPage() {
  const res = await fetch('https://api.example.com/courses', { next: { tags: ['courses'] } });
  const courses = await res.json();
  return <pre>{JSON.stringify(courses, null, 2)}</pre>;
}
```

<Callout type="tip" title="Next.js Best Practice">
Keep Server Components as your default, validate every Server Action and Route Handler input on the server, and verify your production bundle size with `next build` before shipping.
</Callout>

## Key Takeaways

- **Await databases or fetch() directly inside Server Components**
- **Eliminate client-side waterfalls with Promise.all()**
- **Invalidate cached views on demand via revalidatePath and revalidateTag**
