## Overview

Build REST endpoints, webhooks, and health checks using app/api/.../route.ts with standard Web Request and Response objects.

Next.js App Router unifies server rendering, streaming, type-safe mutations, and edge-ready caching inside a single React + TypeScript codebase.

## Production Code Example

```tsx
// app/api/health/route.ts
import { NextResponse } from 'next/server';

export async function GET() {
  return NextResponse.json({ ok: true, timestamp: Date.now() }, { status: 200 });
}
```

<Callout type="tip" title="Next.js Best Practice">
Keep Server Components as your default, validate every Server Action and Route Handler input on the server, and verify your production bundle size with `next build` before shipping.
</Callout>

## Key Takeaways

- **Export named HTTP verb handlers (GET, POST, PUT, DELETE) in route.ts**
- **Validate request JSON and return proper 400/401/404 status codes**
- **Keep webhook signature verification strictly on the server**
