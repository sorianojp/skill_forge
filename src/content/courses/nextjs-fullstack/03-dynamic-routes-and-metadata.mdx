## Overview

Create dynamic [slug] pages, pre-render static paths with generateStaticParams, and generate per-page OpenGraph metadata.

Next.js App Router unifies server rendering, streaming, type-safe mutations, and edge-ready caching inside a single React + TypeScript codebase.

## Production Code Example

```tsx
// app/courses/[slug]/page.tsx
import type { Metadata } from 'next';

export async function generateMetadata({ params }: { params: Promise<{ slug: string }> }): Promise<Metadata> {
  const { slug } = await params;
  return { title: `${slug} | DevPath` };
}
```
