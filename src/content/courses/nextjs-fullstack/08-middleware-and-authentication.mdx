## Overview

Protect private dashboards using HttpOnly signed session cookies, middleware redirects, and server-side session checks.

Next.js App Router unifies server rendering, streaming, type-safe mutations, and edge-ready caching inside a single React + TypeScript codebase.

## Production Code Example

```tsx
// middleware.ts
import { NextResponse, type NextRequest } from 'next/server';

export function middleware(req: NextRequest) {
  const hasSession = req.cookies.has('devpath_session');
  if (!hasSession && req.nextUrl.pathname.startsWith('/dashboard')) {
    return NextResponse.redirect(new URL('/login', req.url));
  }
  return NextResponse.next();
}
```

## Key Takeaways

- **Store session tokens in HttpOnly, Secure, SameSite=Lax cookies instead of localStorage**
- **Use middleware.ts for lightweight optimistic redirects**
- **Always re-verify session authorization inside Server Components and Actions**
