## Overview

Show instant skeletons and isolate slow widgets or runtime failures with React Suspense, loading.tsx, and error.tsx.

Next.js App Router unifies server rendering, streaming, type-safe mutations, and edge-ready caching inside a single React + TypeScript codebase.

## Production Code Example

```tsx
// app/dashboard/page.tsx
import { Suspense } from 'react';
import { SlowStats } from './SlowStats';

export default function DashboardPage() {
  return (
    <section>
      <h1>Dashboard</h1>
      <Suspense fallback={<p>Loading metrics...</p>}>
        <SlowStats />
      </Suspense>
    </section>
  );
}
```

<Callout type="tip" title="Next.js Best Practice">
Keep Server Components as your default, validate every Server Action and Route Handler input on the server, and verify your production bundle size with `next build` before shipping.
</Callout>

## Key Takeaways

- **Add route-level skeleton UI with loading.tsx**
- **Stream slow sub-panels independently with `<Suspense>` fallbacks**
- **Recover gracefully from errors using a 'use client' error.tsx boundary**
