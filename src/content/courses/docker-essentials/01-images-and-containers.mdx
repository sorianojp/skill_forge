**Docker** packages your code, runtime, and system libraries into a portable **image** so "it works on my machine" becomes "it works identically on every laptop and cloud server."

- **Image:** Immutable read-only template (like a class).
- **Container:** A lightweight running process created from an image (like an object instance).

<Callout type="tip" title="Remember Port Mapping Direction (-p HOST:CONTAINER)">
  <code>docker run -d -p 8080:80 nginx</code> maps port <code>8080</code> on your machine to port <code>80</code> inside the Nginx container.
</Callout>
