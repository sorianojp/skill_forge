A **multi-stage Dockerfile** compiles your app in a full SDK stage (`AS builder`) and copies *only* the final binary or `dist/` folder into a tiny runtime stage (`nginx:alpine` or `distroless`), stripping out build tools, compilers, and source code from production.

<Callout type="tip" title="Run Containers as Non-Root">
  Adding <code>USER node</code> (or creating a non-root app user) reduces blast radius if an application vulnerability is ever exploited.
</Callout>
