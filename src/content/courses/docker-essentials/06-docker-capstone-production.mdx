A production-ready container follows five golden rules: **pinned base tag**, **`.dockerignore`**, **multi-stage build**, **non-root `USER`**, and a **`HEALTHCHECK`** endpoint.

## Capstone Audit Lab

<CodeLab
  client:visible
  title="audit_dockerfile.sh"
  language="bash"
  code={`dockerfile=$(cat << 'EOF'
FROM python:3.12-slim
WORKDIR /app
COPY server.py .
USER nobody
EXPOSE 8787
CMD ["python3", "server.py"]
EOF
)

echo "$dockerfile" | grep -q "USER " && echo "[PASS] Non-root user configured"
echo "$dockerfile" | grep -q ":latest" || echo "[PASS] Base image tag pinned"`}
  expectedOutput={`[PASS] Non-root user configured
[PASS] Base image tag pinned`}
/>
