Every `RUN`, `COPY`, and `ADD` instruction creates a **cached layer**. If you copy `package.json` and run `npm ci` *before* copying `src/`, Docker reuses the cached dependency layer whenever you edit source code, turning 60-second builds into 2-second builds.

<Callout type="warning" title="Always Include a .dockerignore">
  Without a <code>.dockerignore</code> excluding <code>node_modules</code>, <code>.git</code>, and <code>.env</code>, Docker sends hundreds of megabytes of build context and risks baking secrets into your image!
</Callout>
