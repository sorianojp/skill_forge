In production, your PostgreSQL or Redis container should **never** publish `5432:5432` to the public internet. Instead, attach `api` and `db` to the same private **Docker bridge network** so `api` talks to `db:5432` internally while only Nginx (`80`/`443`) faces the outside world.

<Callout type="tip" title="User-Defined Bridges Beat the Default Bridge">
  User-defined bridge networks automatically resolve containers by name (<code>ping db</code>), whereas Docker's legacy default bridge does not.
</Callout>
