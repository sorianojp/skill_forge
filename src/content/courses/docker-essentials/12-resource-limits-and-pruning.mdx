By default, a single container can consume 100% of your server's RAM and CPU. Setting **`--memory 256m --cpus 0.5`** protects neighboring services on small VPS droplets. Also monitor disk space periodically with `docker system df` and clear old unused layers with `docker image prune -f`.

<Callout type="warning" title="Be Careful with --volumes on prune">
  Running <code>docker system prune -af</code> is safe for unused images and build cache, but never add <code>--volumes</code> unless you are certain no stopped database volume holds data you still need!
</Callout>
