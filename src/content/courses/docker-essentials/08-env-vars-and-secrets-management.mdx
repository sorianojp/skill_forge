A great Docker image is **environment-agnostic**: the exact same image runs in staging and production, with configuration (`DATABASE_URL`, `PORT`) injected at **runtime** via `--env-file .env` or Compose `env_file`.

<Callout type="warning" title="Never Bake Secrets Into Dockerfile Layers">
  Anyone with access to a Docker image can run <code>docker history</code> or inspect its layers. Always pass secrets at runtime, never with <code>COPY .env</code> or <code>ENV API_KEY=...</code>.
</Callout>
