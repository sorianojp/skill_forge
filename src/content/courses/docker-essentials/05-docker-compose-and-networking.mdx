**Docker Compose** lets you describe your entire multi-container architecture (frontend, backend API, PostgreSQL, Redis) in one declarative `compose.yaml` file. Services on the same Compose network automatically resolve each other by **service name** (e.g., `DATABASE_URL=postgres://user:pass@db:5432/app`).

<Callout type="tip" title="Never Hardcode localhost Between Containers">
  Inside a container, <code>localhost</code> refers to the container itself, not sibling containers. Always connect using the Compose service name (like <code>db</code> or <code>redis</code>).
</Callout>
