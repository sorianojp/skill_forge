When a container exits immediately or misbehaves, follow this 3-step triage checklist:

1. `docker ps -a` -> Check exit code (`Exit 137` = OOM killed; `Exit 1` = app crash).
2. `docker logs --tail 100 <name>` -> Read the exact crash stack trace.
3. `docker exec -it <name> sh` -> Step inside a running container to test env vars, DNS, or files.

<Callout type="info" title="Exit Code 137 Means Out-Of-Memory (OOM)">
  If you see <code>Exited (137)</code>, the Linux kernel killed the container for exceeding its RAM limit. Check <code>docker stats</code> and memory limits.
</Callout>
