In production CI/CD, tag every built image with its **Git commit SHA** (`ghcr.io/team/api:9482a50`) or SemVer tag (`v1.4.2`). If a release has a bug, rolling back takes 5 seconds: just deploy the previous immutable tag!

<Callout type="tip" title="Tag Both the Commit SHA and SemVer">
  Immutable SHA tags let you trace any running production container directly back to the exact Git commit that built it.
</Callout>
