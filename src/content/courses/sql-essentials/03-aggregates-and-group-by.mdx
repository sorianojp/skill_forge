Aggregate functions turn hundreds of raw rows into clean executive metrics.

<Callout type="note" title="WHERE vs. HAVING">
  <code>WHERE</code> filters individual rows <strong>before</strong> grouping. <code>HAVING</code> filters aggregated groups <strong>after</strong> <code>GROUP BY</code> (for example, <code>HAVING COUNT(*) &gt;= 2</code>).
</Callout>

## Try It Yourself

<SqlPlayground
  client:visible
  title="Average Score by Track"
  schemaSql={`CREATE TABLE enrollments (
  id INTEGER PRIMARY KEY,
  learner TEXT,
  track TEXT,
  score INTEGER
);
INSERT INTO enrollments VALUES
  (1, 'Maya', 'HTML', 90),
  (2, 'Liam', 'HTML', 96),
  (3, 'Sofia', 'SQL', 98),
  (4, 'Aira', 'SQL', 92),
  (5, 'Noah', 'CSS', 84);`}
  query={`SELECT
  track,
  COUNT(*) AS total_learners,
  ROUND(AVG(score), 1) AS avg_score
FROM enrollments
GROUP BY track
HAVING COUNT(*) >= 2
ORDER BY avg_score DESC;`}
/>
