`GROUP BY` collapses many rows into one summary row per group. **Window Functions** (`OVER (...)`) compute rankings or running totals while **keeping every individual row intact**!

<Callout type="tip" title="Top-N Per Category">
  Pairing a CTE with <code>ROW_NUMBER() OVER (PARTITION BY track ORDER BY score DESC)</code> lets you fetch the #1 learner in every track in a single clean query.
</Callout>

## Try It Yourself

<SqlPlayground
  client:visible
  title="Per-Track Leaderboard with RANK()"
  schemaSql={`CREATE TABLE enrollments (name TEXT, track TEXT, score INTEGER);
INSERT INTO enrollments VALUES
  ('Maya', 'HTML', 94), ('Liam', 'HTML', 88),
  ('Sofia', 'SQL', 98), ('Aira', 'SQL', 92), ('Noah', 'SQL', 92);`}
  query={`SELECT
  track,
  name,
  score,
  RANK() OVER (PARTITION BY track ORDER BY score DESC) AS track_rank
FROM enrollments
ORDER BY track, track_rank;`}
/>
