Real-world datasets are messy: inconsistent casing, trailing spaces, and raw ISO timestamps. Built-in SQL scalar functions let you normalize data right inside your query.

## Try It Yourself

<SqlPlayground
  client:visible
  title="Text Cleanup & Monthly Grouping"
  schemaSql={`CREATE TABLE signups (id INTEGER PRIMARY KEY, email TEXT, created_at TEXT);
INSERT INTO signups VALUES
  (1, '  Ada@Example.COM ', '2026-10-05'),
  (2, 'Maya@Example.com', '2026-11-12'),
  (3, 'Liam@Example.com', '2026-11-24');`}
  query={`SELECT
  LOWER(TRIM(email)) AS clean_email,
  strftime('%Y-%m', created_at) AS signup_month
FROM signups
ORDER BY created_at;`}
/>
