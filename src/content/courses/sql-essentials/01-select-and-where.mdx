**SQL (Structured Query Language)** is the universal language for working with relational databases like PostgreSQL, MySQL, and SQLite.

## Anatomy of a Basic Query

```sql
SELECT title, track, lessons
FROM courses
WHERE lessons >= 10;
```

<Callout type="tip" title="Name Your Columns Explicitly">
  In production apps, prefer listing exact columns (<code>SELECT id, title</code>) instead of <code>SELECT *</code> so queries stay fast and predictable as tables grow.
</Callout>
