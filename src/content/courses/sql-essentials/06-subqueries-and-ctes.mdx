When a query needs two logical steps (for example, compute each track's average score, then pick tracks above 90), **`WITH` Common Table Expressions (CTEs)** keep your SQL readable from top to bottom.

```sql
WITH track_avgs AS (
  SELECT track, ROUND(AVG(score), 1) AS avg_score
  FROM enrollments
  GROUP BY track
)
SELECT track, avg_score
FROM track_avgs
WHERE avg_score >= 90;
```

<Callout type="tip" title="CTEs Beat Deeply Nested Subqueries">
  Named CTEs read like clean variables in code and make debugging complex analytics queries dramatically easier.
</Callout>

## Try It Yourself

<SqlPlayground
  client:visible
  title="Find Learners Above the Overall Average"
  schemaSql={`CREATE TABLE learners (id INTEGER PRIMARY KEY, name TEXT, score INTEGER);
INSERT INTO learners VALUES (1, 'Maya', 94), (2, 'Liam', 78), (3, 'Sofia', 96), (4, 'Noah', 82);`}
  query={`WITH stats AS (
  SELECT AVG(score) AS overall_avg FROM learners
)
SELECT l.name, l.score, ROUND(s.overall_avg, 1) AS overall_avg
FROM learners l, stats s
WHERE l.score > s.overall_avg
ORDER BY l.score DESC;`}
/>
