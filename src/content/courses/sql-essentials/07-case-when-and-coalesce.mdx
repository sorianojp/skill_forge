In SQL, `NULL` represents an **unknown or missing value**. Because unknown never equals unknown, `col = NULL` is never true. Always write `col IS NULL` or wrap nullable columns in **`COALESCE(col, 'Fallback')`**.

<Callout type="tip" title="CASE Expressions Inside Aggregates">
  Combine <code>SUM(CASE WHEN score &gt;= 80 THEN 1 ELSE 0 END)</code> to count passing learners in one clean pass!
</Callout>

## Try It Yourself

<SqlPlayground
  client:visible
  title="CASE WHEN Buckets + COALESCE"
  schemaSql={`CREATE TABLE learners (id INTEGER PRIMARY KEY, name TEXT, nickname TEXT, score INTEGER);
INSERT INTO learners VALUES
  (1, 'Maya', 'May', 95),
  (2, 'Liam', NULL, 82),
  (3, 'Noah', NULL, 71);`}
  query={`SELECT
  COALESCE(nickname, name) AS display_name,
  score,
  CASE
    WHEN score >= 90 THEN 'Honors'
    WHEN score >= 80 THEN 'Passed'
    ELSE 'Needs Review'
  END AS result
FROM learners
ORDER BY score DESC;`}
/>
