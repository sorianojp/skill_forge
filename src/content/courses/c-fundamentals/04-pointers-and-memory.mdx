A **pointer** is a variable whose value is the **memory address** of another variable. Mastering two operators unlocks pointers completely:

- **`&x`** (address-of): produces the memory address of `x`.
- **`*p`** (dereference): reads or writes the value stored at address `p`.

<Callout type="warning" title="Never Dereference NULL or Uninitialized Pointers">
  Always initialize pointers (to a valid address or <code>NULL</code>) and check <code>if (p != NULL)</code> before dereferencing to avoid segmentation faults.
</Callout>

<CodeLab

void swap(int *a, int *b) {
    int tmp = *a;
    *a = *b;
    *b = tmp;
}

    int x = 10, y = 25;
    swap(&x, &y);
    printf("After swap: x=%d, y=%d\\n", x, y);

}`}
