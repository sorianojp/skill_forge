**C** is a compiled, statically typed systems language designed for speed and direct hardware control. Every C program starts executing in `main()`, and returning `0` signals success to the operating system.

## Core Types & Format Specifiers

- `int` -> `%d` (signed integer, typically 32-bit)
- `double` -> `%f` or `%.2f` (double-precision floating-point)
- `char` -> `%c` (single ASCII byte)
- `const char *` -> `%s` (null-terminated string)

<Callout type="tip" title="Always Compile With Warnings Enabled">
  When compiling locally with GCC or Clang, run <code>cc -std=c11 -Wall -Wextra -Werror main.c -o app</code> so the compiler catches subtle bugs before your program ever runs.
</Callout>
