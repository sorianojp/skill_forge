Because C does not include a built-in `std::vector`, building a lightweight **dynamic array** (`data`, `len`, `cap`) is a classic systems skill. Doubling capacity whenever `len == cap` makes appending amortized $O(1)$.

<Callout type="warning" title="Assign realloc() to a Temporary Pointer">
  Never write <code>ptr = realloc(ptr, new_size);</code> directly! If <code>realloc</code> fails and returns <code>NULL</code>, you would overwrite and leak your original pointer.
</Callout>

## Live Code Lab

<CodeLab
  client:visible
  title="dynarray.c"
  language="c"
  code={`#include <stdio.h>
#include <stdlib.h>

typedef struct {
    int *data;
    size_t len;
    size_t cap;
} IntVec;

void vec_push(IntVec *v, int val) {
    if (v->len == v->cap) {
        size_t next_cap = v->cap ? v->cap * 2 : 2;
        int *tmp = realloc(v->data, next_cap * sizeof(int));
        if (!tmp) return;
        v->data = tmp;
        v->cap = next_cap;
    }
    v->data[v->len++] = val;
}

int main(void) {
    IntVec v = {NULL, 0, 0};
    for (int i = 1; i <= 5; i++) vec_push(&v, i * 10);
    printf("len=%zu cap=%zu last=%d\\n", v.len, v.cap, v.data[v.len - 1]);
    free(v.data);
    return 0;
}`}
  expectedOutput={`len=5 cap=8 last=50`}
/>
