In C, functions live at memory addresses just like data. Passing a **function pointer** lets libraries like `qsort()` sort arrays of *any* type (`int`, `double`, `struct`) by delegating comparisons to your callback function.

<Callout type="tip" title="Safe Integer Comparator">
  In <code>qsort</code> comparators, write <code>(x &gt; y) - (x &lt; y)</code> instead of <code>x - y</code> to avoid signed integer overflow on extreme values.
</Callout>

## Live Code Lab

<CodeLab
  client:visible
  title="qsort_demo.c"
  language="c"
  code={`#include <stdio.h>
#include <stdlib.h>

int cmp_asc(const void *a, const void *b) {
    int x = *(const int *)a;
    int y = *(const int *)b;
    return (x > y) - (x < y);
}

int main(void) {
    int scores[] = {91, 74, 88, 65};
    qsort(scores, 4, sizeof(int), cmp_asc);

    for (int i = 0; i < 4; i++) {
        printf("%d ", scores[i]);
    }
    printf("\\n");
    return 0;
}`}
  expectedOutput={`65 74 88 91`}
/>
