C does not have exceptions (`try/catch`). Instead, standard library functions signal failure via return values (`NULL`, `-1`, or non-zero error codes) and set `errno`. Always check `FILE *f = fopen(...)` before reading or writing, and always call `fclose(f)`.

<Callout type="warning" title="Never Use gets()">
  <code>gets()</code> has no buffer size limit and was removed from the C11 standard because it causes buffer overflows. Always use <code>fgets(buf, sizeof(buf), file)</code>.
</Callout>

int main(void) {
    FILE *out = fopen("/tmp/sf_demo.txt", "w");
    if (!out) {
        fprintf(stderr, "Failed to open file\\n");
        return 1;
    }
    fprintf(out, "DevPath C11 File I/O\\n");
    fclose(out);

    FILE *in = fopen("/tmp/sf_demo.txt", "r");
    char line[64];
    if (in && fgets(line, sizeof(line), in)) {
        printf("Read: %s", line);
        fclose(in);
    }
    return 0;
}`}
