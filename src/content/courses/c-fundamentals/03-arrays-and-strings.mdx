An **array** in C is a contiguous block of elements in memory with zero hidden metadata: C does not store the array's length next to it, and it does not perform automatic bounds checking.

## C Strings Are `char` Arrays Ending in `'\0'`

The literal `"Hi"` occupies **3 bytes**: `'H'`, `'i'`, and `'\0'` (the null byte). Functions like `strlen()` scan forward until they hit `'\0'`.

<Callout type="warning" title="Always Pass Length Alongside Arrays">
  When an array is passed to a function, it decays to a pointer to its first element. Always pass a <code>size_t len</code> parameter alongside it so loops never read past the end.
</Callout>

## Interactive Code Lab

<CodeLab
  client:visible
  title="arrays_strings.c"
  language="c"
  code={`#include <stdio.h>
#include <string.h>

int main(void) {
    int scores[] = {84, 92, 88, 96};
    size_t n = sizeof(scores) / sizeof(scores[0]);
    int sum = 0;

    for (size_t i = 0; i < n; i++) {
        sum += scores[i];
    }

    char name[] = "DevPath";
    printf("Name: %s (len=%zu)\\n", name, strlen(name));
    printf("Average: %.1f\\n", (double)sum / n);
    return 0;
}`}
  expectedOutput={`Name: DevPath (len=7)
Average: 90.0`}
