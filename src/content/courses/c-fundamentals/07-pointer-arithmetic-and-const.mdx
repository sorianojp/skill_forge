In C, adding `1` to an `int *p` advances the address by **`sizeof(int)`** bytes (typically 4 bytes), pointing directly to the next integer in the array. In fact, `arr[i]` is literally defined by the C standard as `*(arr + i)`.

<Callout type="info" title="Reading Const Pointers">
  <code>const int *p</code> means the integer pointed to is read-only. <code>int *const p</code> means the pointer address itself cannot be reassigned.
</Callout>
