A **`struct`** groups related fields of different types into one contiguous record. When you need data whose size is determined at runtime or must outlive a function call, allocate it on the **heap** with `malloc()` and always pair it with `free()`.

## Dot (`.`) vs. Arrow (`->`)

- Use `user.age` when you have a `User` value.
- Use `ptr->age` (shorthand for `(*ptr).age`) when you have a `User *` pointer.

<Callout type="warning" title="Every malloc Needs a Matching free">
  Forgetting to call <code>free(ptr)</code> leaks memory; calling <code>free</code> twice or using memory after freeing causes undefined behavior. Set <code>ptr = NULL;</code> after freeing as a clean safeguard.
</Callout>

## Interactive Code Lab

<CodeLab
  client:visible
  title="structs_heap.c"
  language="c"
  code={`#include <stdio.h>
#include <stdlib.h>

typedef struct {
    const char *name;
    int score;
} Student;

void boost_score(Student *s, int bonus) {
    s->score += bonus;
}

int main(void) {
    Student *s = malloc(sizeof(Student));
    if (!s) return 1;

    s->name = "Maya";
    s->score = 88;
    boost_score(s, 7);

    printf("%s scored %d\\n", s->name, s->score);
    free(s);
    return 0;
}`}
  expectedOutput={`Maya scored 95`}
/>
