Before the C compiler parses your code, the **preprocessor** handles directives starting with `#` (`#include`, `#define`, `#ifdef`). Putting declarations in `.h` headers with **include guards** prevents multiple-inclusion errors across multi-file projects.

<Callout type="warning" title="Macro Trap: Double Evaluation">
  A macro like <code>#define SQUARE(x) ((x) * (x))</code> evaluates <code>SQUARE(i++)</code> twice! Prefer <code>static inline int square(int x)</code> for type safety and single evaluation.
</Callout>

    if (v > hi) return hi;
    return v;
}
