Systems code in C relies heavily on **enums** for state machines and **bitwise flags** (`1 << 0`, `1 << 1`, `1 << 2`) to pack permissions or configuration options into a single byte or integer.

- **Set flag:** `perms |= FLAG_WRITE;`
- **Check flag:** `if (perms & FLAG_WRITE)`
- **Clear flag:** `perms &= ~FLAG_WRITE;`

<Callout type="tip" title="Bitwise vs. Logical Operators">
  Use single <code>&amp;</code> and <code>|</code> for bitwise flag operations, and double <code>&amp;&amp;</code> and <code>||</code> for boolean conditions.
</Callout>

enum {
    FLAG_READ  = 1 << 0,
    FLAG_WRITE = 1 << 1,
    FLAG_EXEC  = 1 << 2
};

int main(void) {
    unsigned int perms = FLAG_READ | FLAG_WRITE;
    printf("Can write? %s\\n", (perms & FLAG_WRITE) ? "yes" : "no");
    printf("Can exec?  %s\\n", (perms & FLAG_EXEC)  ? "yes" : "no");
    return 0;
}`}
