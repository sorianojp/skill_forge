C reads source files top-to-bottom. Placing a **function prototype** (declaration) above `main()` lets the compiler check argument types even when the full implementation is placed below `main()`.

## Pass-by-Value by Default

When you pass an `int` to a C function, C copies the value. Modifying the parameter inside the function does **not** change the caller's original variable (unless you pass a pointer, which we cover in Lesson 4).

<Callout type="info" title="Don't Forget break in switch">
  In C, <code>switch</code> cases fall through to the next case automatically unless you end each case with <code>break;</code> or <code>return</code>.
</Callout>
