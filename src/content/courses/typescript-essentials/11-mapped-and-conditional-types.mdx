Built-in utilities like `Partial<T>` and `Readonly<T>` are not compiler magic; they are written using **mapped types**:

```ts
type MyReadonly<T> = { readonly [K in keyof T]: T[K] };
```

Knowing mapped types lets you create domain-specific helpers like `Nullable<T>` or `Flags<T>` in two lines.

<Callout type="info" title="Keep Type-Level Logic Readable">
  Simple mapped and conditional types eliminate duplication. If a type takes more than 5 lines to understand, prefer simpler explicit interfaces.
</Callout>
