TypeScript uses **structural typing**: any object that has the required properties with matching types satisfies an `interface`, even without explicitly naming it.

<Callout type="tip" title="readonly Prevents Accidental Mutation">
  Marking IDs or config fields <code>readonly id: string</code> makes the compiler catch accidental reassignments immediately.
</Callout>
