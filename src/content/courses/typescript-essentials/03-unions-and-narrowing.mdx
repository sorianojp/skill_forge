**Discriminated unions** are one of TypeScript's superpowers. By giving each variant in a union a literal tag (like `status: "ok"` vs `status: "error"`), TypeScript automatically narrows which properties exist inside each `if` or `switch` branch.

<Callout type="tip" title="Replace Boolean Soup with Literal Unions">
  Instead of <code>isLoading: boolean; isError: boolean; isSuccess: boolean</code>, use a single <code>status: "idle" | "loading" | "error" | "success"</code> so impossible states cannot happen.
</Callout>

## Live Code Lab

<CodeLab
  client:visible
  title="narrowing.ts"
  language="ts"
  code={`type LoadState =
  | { status: "loading" }
  | { status: "ready"; items: number }
  | { status: "error"; message: string };

function describe(state: LoadState): string {
  switch (state.status) {
    case "loading": return "Loading...";
    case "ready": return "Loaded " + state.items + " items";
    case "error": return "Error: " + state.message;
  }
}

console.log(describe({ status: "ready", items: 12 }));
console.log(describe({ status: "error", message: "Timeout" }));`}
  expectedOutput={`Loaded 12 items
Error: Timeout`}
/>
