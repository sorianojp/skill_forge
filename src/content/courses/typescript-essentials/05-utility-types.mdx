TypeScript ships with built-in **utility types** so you never have to copy-paste interfaces:

- `Partial<User>`: makes every field optional (perfect for `updateUser(id, patch)`).
- `Pick<User, "id" | "name">`: keeps only selected properties.
- `Omit<User, "passwordHash">`: strips sensitive fields before returning an API response.
- `Record<string, number>`: maps string keys to number values.

<Callout type="tip" title="Single Source of Truth">
  Deriving DTO types with <code>Pick</code> and <code>Omit</code> guarantees that when your core domain model changes, every derived type updates automatically.
</Callout>

  id: string;
  name: string;
  score: number;
}

function patchLearner(base: Learner, patch: Partial<Learner>): Learner {
  return { ...base, ...patch };
}

const u1: Learner = { id: "u1", name: "Maya", score: 82 };
const u2 = patchLearner(u1, { score: 96 });
console.log(u2.name + ": " + u2.score);`}
