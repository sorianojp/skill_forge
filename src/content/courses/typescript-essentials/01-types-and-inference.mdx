**TypeScript** is JavaScript with static type checking. Types are checked at compile time and erased completely before your code runs, giving you zero runtime overhead and instant editor autocomplete.

<Callout type="warning" title="Prefer unknown Over any">
  <code>any</code> turns off the type checker completely. Use <code>unknown</code> for untrusted inputs (like parsed JSON), which forces you to narrow the type before using it.
</Callout>
