When `typeof` or `instanceof` is not enough, a **custom type guard** (`function isUser(x: unknown): x is User`) teaches the TypeScript compiler how to narrow an arbitrary value inside `if (isUser(data))` or `items.filter(isDefined)`.

<Callout type="tip" title="Cleanly Filter Out null and undefined">
  Passing a predicate <code>(x: T | null | undefined): x is T =&gt; x != null</code> to <code>.filter()</code> narrows <code>(string | null)[]</code> into <code>string[]</code> automatically.
</Callout>
