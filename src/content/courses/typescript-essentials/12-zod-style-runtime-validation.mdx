Because TypeScript erases all types during compilation, `JSON.parse(raw) as User` does **not** actually check the data at runtime! Always validate untrusted data at your app's boundaries (using a small validator function or libraries like Zod / Valibot) so internal code can trust its types 100%.

<Callout type="warning" title="Avoid Blind 'as MyType' on JSON.parse">
  Type assertions (<code>as User</code>) tell the compiler to stop checking. Parse into <code>unknown</code> first and validate required fields before returning a typed object.
</Callout>

<CodeLab

  code={`interface CertPayload {
  id: string;
  score: number;
}

function parseCert(raw: unknown): CertPayload | null {
  if (typeof raw !== "object" || raw === null) return null;
  const obj = raw as Record<string, unknown>;
  if (typeof obj.id !== "string" || typeof obj.score !== "number") return null;
  return { id: obj.id, score: obj.score };
}

console.log("Valid:", parseCert({ id: "DP-TS-101", score: 92 }));
console.log("Bad:  ", parseCert({ id: 123 }));`}
