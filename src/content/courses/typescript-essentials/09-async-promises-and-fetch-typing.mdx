Every `async` function automatically wraps its return value in a **`Promise<T>`**. When calling `Promise.all([fetchUser(), fetchScore()])`, TypeScript automatically preserves a strongly typed tuple `[User, number]`.

<Callout type="info" title="Awaited<T> Unwraps Nested Promises">
  <code>type Data = Awaited&lt;ReturnType&lt;typeof loadCourse&gt;&gt;;</code> extracts the exact resolved payload type without duplicating interfaces.
</Callout>

## Live Code Lab

<CodeLab
  client:visible
  title="async_ts.ts"
  language="ts"
  code={`interface TrackInfo {
  name: string;
  lessons: number;
}

async function fetchTrack(name: string): Promise<TrackInfo> {
  return { name, lessons: 12 };
}

async function main() {
  const [ts, react] = await Promise.all([
    fetchTrack("TypeScript"),
    fetchTrack("React"),
  ]);
  console.log(ts.name + "+" + react.name + " =", ts.lessons + react.lessons, "lessons");
}

main();`}
  expectedOutput={`TypeScript+React = 24 lessons`}
/>
