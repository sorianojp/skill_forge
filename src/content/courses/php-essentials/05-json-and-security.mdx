When PHP renders HTML or queries SQL databases, two habits protect your users from the two most common web vulnerabilities:

1. **Prevent XSS**: Escape user text before printing into HTML using `htmlspecialchars($text, ENT_QUOTES, 'UTF-8')`.
2. **Prevent SQL Injection**: Always use **PDO prepared statements** (`prepare()` + `execute([$param])`) instead of concatenating variables into SQL strings.

<DoDont
  doTitle="Safe PDO Prepared Statement"
  dontTitle="Vulnerable SQL Concatenation"
  doCode={`$stmt = $pdo->prepare('SELECT * FROM users WHERE email = ?');
$stmt->execute([$email]);
$user = $stmt->fetch();`}
  dontCode={`// NEVER concatenate user input into SQL!
$pdo->query("SELECT * FROM users WHERE email = '$email'");`}
/>

<Callout type="tip" title="Throw on Invalid JSON">
  Pass <code>JSON_THROW_ON_ERROR</code> to <code>json_encode()</code> and <code>json_decode()</code> so malformed JSON fails loudly instead of silently returning <code>null</code>.
</Callout>
