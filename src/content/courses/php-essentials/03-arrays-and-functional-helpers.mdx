PHP arrays work as both ordered lists (`['HTML', 'CSS']`) and key-value maps (`['title' => 'PHP', 'free' => true]`). Combine them with **`array_filter()`**, **`array_map()`**, and short arrow functions (`fn($x) => ...`).

## Try It Yourself

<PhpPlayground
  client:visible
  title="Associative Arrays & Arrow Functions"
  code={`<?php
$scores = [72, 88, 95, 64, 91];
$passing = array_values(array_filter($scores, fn($s) => $s >= 80));
$labels = array_map(fn($s) => "{$s}%", $passing);

echo "Passing count: " . count($passing) . "\\n";
echo "Scores: " . implode(', ', $labels) . "\\n";`}
/>
