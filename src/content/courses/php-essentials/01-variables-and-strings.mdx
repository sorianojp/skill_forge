**PHP 8** powers a massive portion of the modern web (from Laravel and Symfony to WordPress). Every variable starts with `$`, and statements end with `;`.

## String Interpolation vs. Single Quotes

- **Double quotes (`"..."`)** evaluate variables like `"Hello, $name!"`.
- **Single quotes (`'...'`)** print text literally without parsing variables.

<Callout type="tip" title="Always Enable Strict Types">
  Adding <code>declare(strict_types=1);</code> at the top of modern PHP 8 files catches accidental type mismatches early.
</Callout>
