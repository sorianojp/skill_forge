Modern PHP 8 eliminates boilerplate with **constructor property promotion**: declare visibility (`public`, `private`, `readonly`) directly inside `__construct(...)`!

```php
class Course {
    public function __construct(
        public readonly string $title,
        public readonly int $lessons,
    ) {}
}
```

<Callout type="tip" title="Readonly Properties">
  Marking properties <code>readonly</code> guarantees they are set once in the constructor and cannot be accidentally mutated later.
</Callout>
