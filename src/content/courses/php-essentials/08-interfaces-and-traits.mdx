In object-oriented PHP, **interfaces** define *what* a class can do (a contract), while **traits** let multiple classes share reusable method implementations without deep inheritance trees.

## Try It Yourself

<PhpPlayground
  client:visible
  title="Interface Contract + Reusable Trait"
  code={`<?php
interface Scorable {
    public function percent(): int;
}

trait Passable {
    public function passed(): bool {
        return $this->percent() >= 80;
    }
}

class ExamAttempt implements Scorable {
    use Passable;
    public function __construct(private int $correct, private int $total) {}
    public function percent(): int {
        return (int) round(($this->correct / $this->total) * 100);
    }
}

$attempt = new ExamAttempt(9, 10);
echo "Score: {$attempt->percent()}% | Passed: " . ($attempt->passed() ? 'Yes' : 'No') . "\\n";`}
/>
