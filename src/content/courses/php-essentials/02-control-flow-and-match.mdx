PHP 8 introduced **`match`**, a safer, stricter, and shorter upgrade to `switch`. It uses strict `===` comparisons, needs no `break` statements, and returns a value directly!

```php
$badge = match ($track) {
    'HTML', 'CSS' => 'Frontend Core',
    'SQL', 'PHP' => 'Backend Stack',
    default => 'General Track',
};
```

<Callout type="tip" title="Key + Value in foreach">
  Write <code>foreach ($counts as $track =&gt; $lessons)</code> to access both the key and value in one clean loop.
</Callout>
