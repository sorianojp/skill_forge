In modern PHP projects (like Laravel or Symfony), you never write dozens of manual `require 'file.php';` lines. Instead, **Composer** generates a single `vendor/autoload.php` using **PSR-4**:

```json
{
  "autoload": {
    "psr-4": {
      "DevPath\\": "src/"
    }
  }
}
```

With that mapping, `DevPath\Courses\Lesson` automatically loads from `src/Courses/Lesson.php`!

<Callout type="tip" title="One Class Per File">
  Match the filename exactly to the class name (<code>Lesson.php</code> for <code>class Lesson</code>) so PSR-4 autoloading works identically on both macOS and case-sensitive Linux servers.
</Callout>
