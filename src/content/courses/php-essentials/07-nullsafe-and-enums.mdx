## Backed Enums

Instead of passing magic strings like `'beginner'` or `'pro'` everywhere (where a typo silently breaks logic), PHP 8.1 **Enums** let the type system enforce valid values:

```php
enum Level: string {
    case Beginner = 'beginner';
    case Intermediate = 'intermediate';
}
```

<Callout type="tip" title="Combine ?-> with ??">
  Write <code>$city = $user?-&gt;profile?-&gt;city ?? 'Unknown';</code> to safely read nested properties in one clean line.
</Callout>
