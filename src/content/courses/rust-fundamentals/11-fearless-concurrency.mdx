## Overview

Use Send/Sync traits, std::thread, mpsc channels, and `Arc<Mutex<T>`> so data races are impossible in safe Rust.

## Code Example

```rust
use std::sync::{Arc, Mutex};
use std::thread;

fn main() {
    let counter = Arc::new(Mutex::new(0));
    let c = Arc::clone(&counter);
    let handle = thread::spawn(move || { *c.lock().unwrap() += 1; });
    handle.join().unwrap();
    println!("{}", *counter.lock().unwrap());
}
```
