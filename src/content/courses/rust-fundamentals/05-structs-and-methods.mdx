## Overview

Model domain data with structs, attach methods with impl, and write constructors like Self::new().

## Code Example

```rust
#[derive(Debug)]
struct Course {
    slug: String,
    hours: u32,
}

impl Course {
    fn summary(&self) -> String {
        format!("{} ({}h)", self.slug, self.hours)
    }
}
```

<Callout type="tip" title="Rustaceans' Habit">
Read compiler error messages carefully and run `cargo clippy` often. Rust's compiler is designed to teach you safer, faster patterns before your code ever runs.
</Callout>

## Key Takeaways

- **Define named structs and derive Debug / Clone**
- **Choose between &self, &mut self, and self receivers**
- **Write clean constructors with associated functions**
