## Overview

Start with Cargo projects, immutable-by-default bindings, explicit mut, and strong static types.

## Code Example

```rust
fn main() {
    let track = "Rust";
    let mut lessons = 11;
    lessons += 1;
    println!("Learning {track}: {lessons} lessons");
}
```

<Callout type="tip" title="Rustaceans' Habit">
Read compiler error messages carefully and run `cargo clippy` often. Rust's compiler is designed to teach you safer, faster patterns before your code ever runs.
</Callout>

## Key Takeaways

- **Create and run projects with cargo new and cargo run**
- **Understand why variables are immutable by default unless marked mut**
- **Use shadowing and explicit integer/float types cleanly**
