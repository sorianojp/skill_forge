## Overview

Work with heap-allocated `Vec<T>` and `HashMap<K, V>` using idiomatic .entry().or_insert() patterns.

## Code Example

```rust
use std::collections::HashMap;

fn main() {
    let mut counts: HashMap<&str, u32> = HashMap::new();
    for word in ["rust", "go", "rust"] {
        *counts.entry(word).or_insert(0) += 1;
    }
    println!("{counts:?}");
}
```
