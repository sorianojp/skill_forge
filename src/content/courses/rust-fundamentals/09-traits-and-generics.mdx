## Overview

Write reusable zero-cost generic functions constrained by traits (Rust's equivalent of interfaces).

## Code Example

```rust
trait Summarize {
    fn summary(&self) -> String;
}

fn print_card<T: Summarize>(item: &T) {
    println!("{}", item.summary());
}
```

<Callout type="tip" title="Rustaceans' Habit">
Read compiler error messages carefully and run `cargo clippy` often. Rust's compiler is designed to teach you safer, faster patterns before your code ever runs.
</Callout>

## Key Takeaways

- **Define shared behavior with trait declarations and impl Trait for Type**
- **Constrain generic type parameters with where clauses**
- **Understand static dispatch (monomorphization) vs dynamic dispatch (dyn Trait)**
