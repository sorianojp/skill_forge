## Overview

Pass data without transferring ownership using shared (&T) and exclusive mutable (&mut T) references.

## Code Example

```rust
fn append_tag(s: &mut String) {
    s.push_str(" [verified]");
}

fn main() {
    let mut title = String::from("Rust");
    append_tag(&mut title);
    println!("{title}");
}
```
