## Overview

Master Rust's signature feature: every value has one owner, moves prevent double-frees, and memory drops deterministically.

## Code Example

```rust
fn main() {
    let s1 = String::from("devpath");
    let s2 = s1; // ownership moved to s2
    println!("{s2}"); // s1 can no longer be used here
}
```

<Callout type="tip" title="Rustaceans' Habit">
Read compiler error messages carefully and run `cargo clippy` often. Rust's compiler is designed to teach you safer, faster patterns before your code ever runs.
</Callout>

## Key Takeaways

- **Explain the three rules of Rust ownership**

- **Know when .clone() is appropriate vs borrowing**
