## Overview

Replace null pointers and hidden exceptions with explicit `Option<T>`, `Result<T, E>`, and clean ? propagation.

## Code Example

```rust
fn parse_port(raw: &str) -> Result<u16, std::num::ParseIntError> {
    let port: u16 = raw.trim().parse()?;
    Ok(port)
}
```
