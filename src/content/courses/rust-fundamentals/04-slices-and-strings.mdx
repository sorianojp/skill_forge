## Overview

Write flexible zero-copy APIs using string slices (&str) and array/vector slices (&[T]).

## Code Example

```rust
fn first_word(s: &str) -> &str {
    s.split_whitespace().next().unwrap_or("")
}

fn main() {
    println!("{}", first_word("fearless concurrency"));
}
```

</Callout>

## Key Takeaways

- **Choose &str for function parameters instead of &String**
- **Borrow contiguous sub-ranges with &[T] slices**
