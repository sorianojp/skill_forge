## Overview

Chain lazy .iter(), .filter(), .map(), and .collect() pipelines that compile down to tight loops.

## Code Example

```rust
fn main() {
    let nums = [1, 2, 3, 4, 5, 6];
    let sum_even: i32 = nums.iter().copied().filter(|n| n % 2 == 0).sum();
    println!("Even sum: {sum_even}");
}
```
