## Overview

Encode rich domain states using enums with attached data and let exhaustive match catch missing cases at compile time.

## Code Example

```rust
enum Status {
    Draft,
    Published { views: u64 },
}

fn describe(s: Status) -> String {
    match s {
        Status::Draft => "Draft".into(),
        Status::Published { views } => format!("Live ({views} views)"),
    }
}
```

<Callout type="tip" title="Rustaceans' Habit">
Read compiler error messages carefully and run `cargo clippy` often. Rust's compiler is designed to teach you safer, faster patterns before your code ever runs.
</Callout>

## Key Takeaways

- **Attach different payload types to each enum variant**
- **Use exhaustive match expressions that refuse to compile if a variant is forgotten**
- **Use if let for concise single-variant matching**
