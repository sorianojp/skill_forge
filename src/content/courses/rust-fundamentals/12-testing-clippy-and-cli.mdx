## Overview

Write inline #[cfg(test)] tests, lint idioms with cargo clippy, and compile optimized release binaries.

## Code Example

```rust
#[cfg(test)]
mod tests {
    #[test]
    fn adds_correctly() {
        assert_eq!(2 + 2, 4);
    }
}
```

<Callout type="tip" title="Rustaceans' Habit">
Read compiler error messages carefully and run `cargo clippy` often. Rust's compiler is designed to teach you safer, faster patterns before your code ever runs.
</Callout>

## Key Takeaways

- **Write fast unit tests right alongside functions with #[test]**
- **Catch non-idiomatic code automatically with cargo clippy**
- **Build optimized binaries with cargo build --release**
