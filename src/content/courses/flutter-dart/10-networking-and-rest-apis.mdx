## Overview

Fetch remote JSON safely with package:http, check HTTP status codes, and render loading/error/data states cleanly.

## Code Example

```dart
final res = await http.get(Uri.parse('https://devpath.mycampus.ph/api/health'));
if (res.statusCode != 200) throw Exception('HTTP ${res.statusCode}');
final data = jsonDecode(res.body) as Map<String, dynamic>;
```
