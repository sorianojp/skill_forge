## Overview

Render thousands of items smoothly using lazy ListView.builder instead of eager Column children.

## Code Example

```dart
ListView.builder(
  itemCount: tracks.length,
  itemBuilder: (context, index) => ListTile(
    title: Text(tracks[index]),
    trailing: const Icon(Icons.chevron_right),
  ),
)
```
