## Overview

Persist user preferences with shared_preferences and structured offline records with sqflite or Drift.

## Code Example

```dart
final prefs = await SharedPreferences.getInstance();
await prefs.setBool('darkMode', true);
final isDark = prefs.getBool('darkMode') ?? false;
```

## Key Takeaways

- **Store simple key-value settings (theme, onboarding) in SharedPreferences**
- **Store relational offline records in SQLite (sqflite/Drift)**
- **Store auth tokens securely in flutter_secure_storage instead of plain prefs**
