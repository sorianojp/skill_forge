## Overview

Navigate cleanly between screens, pass route parameters, and support deep links using go_router.

## Code Example

```dart
final router = GoRouter(
  routes: [
    GoRoute(path: '/', builder: (_, __) => const HomeScreen()),
    GoRoute(path: '/course/:slug', builder: (_, s) => CourseScreen(slug: s.pathParameters['slug']!)),
  ],
);
```
