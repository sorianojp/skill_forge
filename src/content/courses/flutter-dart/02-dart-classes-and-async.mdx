## Overview

Model app data with immutable Dart classes, fromJson factories, and non-blocking Future async/await.

## Code Example

```dart
class Course {
  final String title;
  final int hours;
  const Course({required this.title, required this.hours});

  factory Course.fromJson(Map<String, dynamic> json) =>
      Course(title: json['title'] as String, hours: json['hours'] as int);
}
```

Run `flutter analyze` and `flutter test` regularly, use `const` widgets wherever possible, and keep network calls out of `build()` methods.
