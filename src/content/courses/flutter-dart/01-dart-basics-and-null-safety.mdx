## Overview

Learn Dart's clean syntax, final vs const, sound null safety (?, ??, !), and strong type inference.

## Code Example

```dart
void main() {
  final String name = 'DevPath';
  String? nickname;
  print('Welcome, ${nickname ?? name}!');
}
```
