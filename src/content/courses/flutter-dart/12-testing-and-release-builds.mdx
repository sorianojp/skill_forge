## Overview

Write fast unit and WidgetTester tests and build signed Android App Bundles (AAB) and iOS archives.

## Code Example

```dart
testWidgets('Counter increments on tap', (tester) async {
  await tester.pumpWidget(const MaterialApp(home: CounterCard()));
  await tester.tap(find.byType(ElevatedButton));
  await tester.pump();
  expect(find.text('Clicked 1 times'), findsOneWidget);
});
```

<Callout type="tip" title="Flutter Production Habit">
Run `flutter analyze` and `flutter test` regularly, use `const` widgets wherever possible, and keep network calls out of `build()` methods.
</Callout>

## Key Takeaways

- **Verify UI rendering and tap interactions with testWidgets()**
- **Run flutter analyze to catch lint and null-safety issues before release**
- **Build signed release bundles with flutter build appbundle --release**
