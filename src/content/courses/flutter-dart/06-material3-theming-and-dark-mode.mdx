## Overview

Create cohesive light and dark themes using ColorScheme.fromSeed and Theme.of(context).

## Code Example

```dart
MaterialApp(
  theme: ThemeData(useMaterial3: true, colorSchemeSeed: Colors.blue),
  darkTheme: ThemeData(useMaterial3: true, colorSchemeSeed: Colors.blue, brightness: Brightness.dark),
  themeMode: ThemeMode.system,
)
```

## Key Takeaways

- **Generate harmonious palettes with ColorScheme.fromSeed**
- **Support light, dark, and system ThemeMode effortlessly**
- **Read theme colors via Theme.of(context).colorScheme instead of hardcoded hex codes**
