## Overview

Separate UI from business logic using ChangeNotifier / ValueNotifier or Riverpod so apps stay testable.

## Code Example

```dart
class ProgressNotifier extends ChangeNotifier {
  final Set<String> completed = {};
  void toggle(String id) {
    completed.contains(id) ? completed.remove(id) : completed.add(id);
    notifyListeners();
  }
}
```

<Callout type="tip" title="Flutter Production Habit">
Run `flutter analyze` and `flutter test` regularly, use `const` widgets wherever possible, and keep network calls out of `build()` methods.
</Callout>

## Key Takeaways

- **Distinguish ephemeral local UI state from shared app state**
- **Notify listeners cleanly with ChangeNotifier or Riverpod providers**
- **Avoid prop-drilling state through 6 layers of widgets**
