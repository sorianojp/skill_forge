## Overview

Understand Flutter's declarative UI model ('UI = f(state)'), StatelessWidget, and StatefulWidget with setState.

## Code Example

```dart
class CounterCard extends StatefulWidget {
  const CounterCard({super.key});
  @override
  State<CounterCard> createState() => _CounterCardState();
}

class _CounterCardState extends State<CounterCard> {
  int count = 0;
  @override
  Widget build(BuildContext context) {
    return ElevatedButton(
      onPressed: () => setState(() => count++),
      child: Text('Clicked $count times'),
    );
  }
}
```

<Callout type="tip" title="Flutter Production Habit">
Run `flutter analyze` and `flutter test` regularly, use `const` widgets wherever possible, and keep network calls out of `build()` methods.
</Callout>

## Key Takeaways

- **Build reusable StatelessWidgets for pure presentation**
- **Manage local interactive state with StatefulWidget and setState()**
- **Keep build() methods pure and fast (never call APIs inside build)**
