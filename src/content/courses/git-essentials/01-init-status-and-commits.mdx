**Git** is a distributed version control system that records snapshots of your project over time. Instead of saving `final_v2_real.zip`, every change is tracked in a verifiable commit history.

## The Three Areas of Git

1. **Working Directory:** The files you currently edit on disk.
2. **Staging Area (Index):** The exact changes you select to include in your next snapshot (`git add`).
3. **Repository (`.git`):** Permanent, hashed snapshots (`git commit`).

<Callout type="tip" title="Keep Commits Atomic">
  Each commit should represent one logical change (for example, "Add login validation" rather than "Fix stuff"). Small commits make debugging with <code>git log</code> and <code>git revert</code> effortless.
</Callout>
