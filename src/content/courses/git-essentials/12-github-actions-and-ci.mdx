**GitHub Actions** runs automated workflows whenever events happen in your repository (such as pushing to `main` or opening a Pull Request). Workflows live in `.github/workflows/*.yml`.

## Anatomy of a CI Workflow

- **`on:`** defines triggers (`push`, `pull_request`).
- **`jobs:`** defines isolated virtual machines (`runs-on: ubuntu-latest`).
- **`steps:`** runs actions (`actions/checkout@v4`) and shell commands (`npm ci && npm test`).

<Callout type="tip" title="Protect Your main Branch">
  Combine GitHub Actions with Branch Protection Rules so Pull Requests cannot be merged until automated tests and builds pass green.
</Callout>
