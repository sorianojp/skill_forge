In this capstone, you will simulate shipping a real feature from start to finish: isolating work on a branch, staging and committing cleanly, switching back to `main`, and merging your changes.

## Release Checklist

1. Check `git status` to see modified files.
2. Create a feature branch (`git checkout -b feat-release`).
3. Stage (`git add .`) and commit with a clear message.
4. Return to `main` (`git checkout main`) and merge (`git merge feat-release`).
5. Inspect `git log --oneline` to verify the release commit.
