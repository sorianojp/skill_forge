A **remote** is a hosted copy of your repository (such as on GitHub or GitLab). By convention, your primary remote is named `origin`.

## Fetch vs. Pull

- **`git fetch origin`** downloads new commits and branches from GitHub without touching your working files. It is always safe to run.
- **`git pull origin main`** runs `git fetch` and immediately merges (or rebases) remote changes into your current branch.
- **`git push -u origin feat/cards`** uploads your local branch and sets up upstream tracking so future pushes only need `git push`.

<Callout type="warning" title="Never Force-Push Shared Branches">
  Running <code>git push --force</code> on <code>main</code> rewrites shared history and can wipe out teammates' commits. If you must update a private feature branch after a rebase, prefer <code>git push --force-with-lease</code>.
</Callout>
