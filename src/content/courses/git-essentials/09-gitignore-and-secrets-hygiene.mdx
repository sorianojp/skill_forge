A **`.gitignore`** file tells Git which untracked paths (like `node_modules/`, `dist/`, `.env`, and `.DS_Store`) should never be staged or committed.

## Untracking a File Without Deleting It

If `.env` was already committed before you added it to `.gitignore`, `.gitignore` alone will not untrack it. Run `git rm --cached .env`, commit the removal, and **rotate any exposed secrets immediately**.

<Callout type="warning" title="Commit a .env.example Instead">
  Never commit real credentials. Commit a <code>.env.example</code> file with placeholder values so teammates know which environment variables are required.
</Callout>
