In Git, a **branch** is simply a lightweight movable pointer to a commit. Creating a branch takes milliseconds and lets you build a feature or fix a bug without breaking `main`.

## Everyday Branch Commands

- `git branch` lists local branches (`*` marks the active one).
- `git checkout -b feat/search` (or `git switch -c feat/search`) creates and switches to a new branch.
- `git checkout main` switches back to `main`.
- `git merge feat/search` integrates commits from `feat/search` into your current branch.

<Callout type="info" title="Handling Merge Conflicts">
  A merge conflict happens when two branches edit the exact same lines of a file. Git marks both versions with <code>&lt;&lt;&lt;&lt;&lt;&lt;&lt;</code>, <code>=======</code>, and <code>&gt;&gt;&gt;&gt;&gt;&gt;&gt;</code> so you can keep the right code, run <code>git add</code>, and commit the resolution.
</Callout>
