Accidentally ran `git reset --hard` or deleted a branch before merging? As long as the work was **committed**, Git keeps a local journal of every position `HEAD` pointed to for ~30 days in the **reflog**.

## The 2-Command Rescue

1. Run `git reflog` to find the hash right before the mistake (e.g., `HEAD@{2}`).
2. Create a rescue branch at that commit: `git checkout -b rescue-branch <hash>`.

<Callout type="info" title="Reflog Only Protects Committed Work">
  Uncommitted working-directory edits that were wiped with <code>git reset --hard</code> are not in the reflog. Commit early and often on feature branches.
</Callout>
