Sometimes you need **one** bug-fix commit from a feature branch without merging the entire unfinished branch. **`git cherry-pick <hash>`** copies just that commit onto your current branch.

## Finding Bugs Fast with `git bisect`

When a bug appeared somewhere in the last 1,000 commits, **`git bisect`** performs a binary search across history, pinpointing the exact offending commit in ~10 steps instead of 1,000.

<Callout type="tip" title="Automate Bisect with a Test Command">
  Running <code>git bisect run npm test</code> lets Git test every midpoint automatically and hand you the exact commit that broke the test suite.
</Callout>
