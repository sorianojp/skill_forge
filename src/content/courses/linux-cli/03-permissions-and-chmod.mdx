Linux permissions split into three groups: **Owner**, **Group**, and **Others**. Each group sums three bits: **Read (`4`)**, **Write (`2`)**, and **Execute (`1`)**:

- **`755` (`rwxr-xr-x`)**: Owner can read/write/execute; everyone else can read/execute (standard for scripts and folders).
- **`644` (`rw-r--r--`)**: Owner can read/write; others read-only (standard for web files).
- **`600` (`rw-------`)**: Owner only (required by SSH for private keys like `~/.ssh/id_ed25519`).

<Callout type="warning" title="Never Use chmod 777 in Production">
  <code>chmod 777</code> lets any user on the server overwrite or execute your files. Use <code>755</code> for directories/executables and <code>644</code> or <code>600</code> for files.
</Callout>
