When a production server slows down or refuses connections, five built-in Linux commands tell you almost everything immediately:

- `free -h` -> RAM and swap usage.
- `df -h` -> Disk space per partition.
- `ps aux | grep node` -> Running processes and PIDs.
- `ss -tulpn` -> Which processes are listening on which TCP/UDP ports.
- `systemctl status nginx` / `journalctl -u nginx -n 50` -> Service status and logs.

<Callout type="tip" title="Always Check Disk Space First">
  A 100% full disk (<code>df -h</code>) causes databases, Nginx, and logs to fail with mysterious errors. It is always the first thing to rule out.
</Callout>
