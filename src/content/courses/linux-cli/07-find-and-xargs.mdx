**`find`** searches entire directory trees with precision: find every `.log` file larger than 50 MB, or every `.mdx` lesson under `src/`. Combining `find` with `wc -l` or `xargs` makes bulk file inspection effortless.

<Callout type="tip" title="Always Quote Wildcards in find">
  Write <code>find src -name "&#42;.mdx"</code> (with quotes around <code>"&#42;.mdx"</code>) so Bash does not expand the wildcard before passing it to <code>find</code>.
</Callout>
