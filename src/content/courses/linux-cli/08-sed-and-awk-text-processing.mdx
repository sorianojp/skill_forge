- **`sed`** (stream editor) excels at line-by-line search and replace (`sed 's/http:/https:/g'`).
- **`awk`** excels at structured columns (`$1`, `$2`, `$NF`) and quick numeric totals (`awk '{sum += $2} END {print sum}'`).

<Callout type="tip" title="Preview sed Output Before Using -i">
  Run <code>sed 's/foo/bar/g' file.txt</code> to stdout first. Only add <code>-i</code> (in-place edit) once you confirm the replacement looks right.
</Callout>
