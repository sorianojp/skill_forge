Every production web server, cloud VM, and Docker container runs **Linux**. Mastering the command line lets you deploy, debug logs, and automate workflows in seconds.

- `pwd` prints your current working directory.
- `ls -lah` lists all files (including dotfiles like `.env`) with human-readable sizes.
- `mkdir -p a/b/c` creates parent folders automatically without failing if they already exist.

<Callout type="warning" title="Double-Check Before Running rm -rf">
  Linux has no Recycle Bin on the command line: <code>rm -rf</code> permanently deletes files immediately. Always run <code>ls</code> on the target path first.
</Callout>
