By default, Bash continues executing even if a command fails or a variable is misspelled! Starting every script with **`set -euo pipefail`** turns Bash into a strict, fail-fast automation language:
- `-e`: exit immediately on any non-zero command.
- `-u`: treat unset variables as errors.
- `-o pipefail`: fail a pipeline if *any* stage fails.

<Callout type="tip" title="Always Double-Quote Variables">
  Write <code>cp "$src" "$dst"</code> instead of <code>cp $src $dst</code> so file names containing spaces never break your script.
</Callout>
