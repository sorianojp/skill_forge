When launching a domain or debugging an API outage, three CLI tools save hours:

- **`dig +short devpath.mycampus.ph`** confirms which IP address DNS resolves to.
- **`curl -sI https://devpath.mycampus.ph`** prints only the HTTP status and response headers (`200 OK`, `301`, cache headers).
- **`ss -tulpn`** lists every TCP/UDP port currently listening on the server and which process owns it.

<Callout type="tip" title="Follow Redirects with curl -L">
  Adding <code>-L</code> tells <code>curl</code> to follow <code>301/302</code> redirects (such as HTTP to HTTPS) automatically.
</Callout>
