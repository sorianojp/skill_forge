When you type `python3` or `node`, Linux searches each colon-separated directory in **`$PATH`** from left to right and runs the first matching executable. In Bash scripts, **`${PORT:-8787}`** lets you read an environment variable with a clean fallback if it is unset or empty.

<Callout type="tip" title="No Spaces Around = in Bash">
  Write <code>PORT=8787</code> (zero spaces around <code>=</code>). Writing <code>PORT = 8787</code> tries to execute a command named <code>PORT</code>!
</Callout>
