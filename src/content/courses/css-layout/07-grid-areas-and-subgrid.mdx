## Visual Page Blueprints with `grid-template-areas`

Instead of counting line numbers like `grid-column: 1 / 3`, you can draw your layout directly in CSS:

```css
.page {
  display: grid;
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
  grid-template-columns: 160px 1fr;
  gap: 10px;
}
```

## Aligning Nested Cards with `subgrid`

Ever had a row of 3 cards where one card has a 2-line title and its button doesn't line up with the neighbors? **`grid-template-rows: subgrid`** lets child cards inherit the parent grid's row tracks so every heading, body, and footer aligns perfectly!

<Callout type="tip" title="Baseline Widely Available">
  CSS <code>subgrid</code> is supported across Chrome, Edge, Safari, and Firefox, making pixel-aligned card rows effortless.
</Callout>
