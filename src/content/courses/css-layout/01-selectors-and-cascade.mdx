CSS stands for **Cascading Style Sheets**. The **Cascade** is the exact algorithm browsers use to decide which style wins when multiple rules target the same element.

## Specificity Hierarchy

Think of specificity as a three-column score `(IDs, Classes/Attributes/Pseudo-classes, Elements)`:

| Selector | Score | Example |
| :--- | :--- | :--- |
| Element | `(0, 0, 1)` | `p`, `h1`, `button` |
| Class / Attribute / Pseudo-class | `(0, 1, 0)` | `.btn`, `[type="email"]`, `:hover` |
| ID | `(1, 0, 0)` | `#hero` |

When two rules have the **exact same specificity**, the **last rule in the stylesheet wins**.

}`}

<Callout type="tip" title="Inheritance Saves Code">
  Text properties like <code>color</code>, <code>font-family</code>, and <code>line-height</code> inherit down from parents to children. Box properties like <code>border</code>, <code>padding</code>, and <code>margin</code> do not.
</Callout>
