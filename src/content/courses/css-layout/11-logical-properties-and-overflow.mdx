## Logical Properties

Instead of physical directions (`margin-left`, `margin-right`), modern CSS uses **flow-relative logical properties**:

| Physical | Logical Equivalent | Benefit |
| :--- | :--- | :--- |
| `margin-left` + `margin-right` | `margin-inline` | One shorthand (`margin-inline: auto` centers horizontally!) |
| `padding-top` + `padding-bottom` | `padding-block` | Adapts automatically to right-to-left (RTL) & vertical writing modes |
| `border-left` | `border-inline-start` | Flips to the right automatically in Arabic/Hebrew (`dir="rtl"`) |

## Zero-JS Carousels with Scroll Snap

Add just two properties to turn any horizontal scrolling row into a crisp, touch-friendly snapping carousel:
- Container: `scroll-snap-type: x mandatory;`
- Slides: `scroll-snap-align: start;`

<Callout type="tip" title="Prefer overflow: clip over overflow: hidden">
  <code>overflow: clip</code> clips overflowing visuals without creating a scroll container, so <code>position: sticky</code> inside it keeps working!
</Callout>
