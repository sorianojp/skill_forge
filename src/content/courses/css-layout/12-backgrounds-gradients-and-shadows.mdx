Depth and surface separation guide the user's eye. Modern CSS lets you craft crisp surfaces (gradients, soft elevation shadows, and frosted glass)with zero image assets.

## Realistic Layered Shadows

A single harsh black shadow (`0 4px 10px black`) looks dated. Pair a **tight low-opacity shadow** with a **soft diffused shadow**:

```css
.elevated {
  box-shadow:
    0 1px 2px rgb(15 23 42 / 0.06),
    0 12px 24px -4px rgb(15 23 42 / 0.12);
}
```

<Callout type="warning" title="Keep Contrast Accessible on Glass Surfaces">
  When using <code>backdrop-filter: blur(10px)</code> over colorful backgrounds, use a high-opacity tint (e.g., <code>rgb(255 255 255 / 0.82)</code>) so text still meets WCAG AA contrast.
</Callout>
