Traditional **Media Queries** (`@media`) respond to the whole browser viewport. Modern **Container Queries** (`@container`) let a component respond to **the width of its own parent container**, so the same card looks great in both a narrow sidebar and a wide main column!

## Setting Up a Container Query

1. Mark the parent wrapper with `container-type: inline-size;`.
2. Query it from inside using `@container (min-width: 320px) { ... }`.

<Callout type="tip" title="Baseline Widely Available">
  CSS Container Queries are supported across all modern browsers (Chrome, Edge, Safari, and Firefox). Pair them with mobile-first <code>@media</code> queries for page-level grids.
</Callout>
