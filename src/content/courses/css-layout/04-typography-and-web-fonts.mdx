Over 80% of the web is text. Great typography (like you see on `web.dev`)comes down to four simple CSS habits:

1. **Unitless `line-height`**: Always write `line-height: 1.6` (not `24px`) so child headings scale proportionally.
2. **Readable line length**: Cap prose containers at `max-width: 65ch`.
3. **Balanced headings**: Add `text-wrap: balance` to `h1`–`h3` so multi-line titles wrap evenly instead of leaving one lonely word on the last line.
4. **Tabular numbers**: Add `font-variant-numeric: tabular-nums` on timers, prices, and progress counters so digits don't jitter horizontally as they change!

<Callout type="tip" title="Fast Web Fonts with font-display: swap">
  When loading custom fonts, always include <code>font-display: swap</code> (or <code>&amp;display=swap</code> in Google Fonts) so text appears immediately in a fallback font instead of staying invisible.
</Callout>
