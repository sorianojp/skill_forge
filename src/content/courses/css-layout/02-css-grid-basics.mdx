While Flexbox excels at a single row or column, **CSS Grid** (`display: grid`) lets you control **rows and columns simultaneously**.

## The Magic Responsive One-Liner

```css
.grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(140px, 1fr));
  gap: 12px;
}
```

<Callout type="tip" title="Zero Media Queries">
  <code>repeat(auto-fit, minmax(140px, 1fr))</code> automatically fits as many columns as possible that are at least <code>140px</code> wide, and stretches them evenly to fill the container.
</Callout>
