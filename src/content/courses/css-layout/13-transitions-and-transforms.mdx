Subtle transitions give buttons and cards tactile feedback. To keep animations at a buttery **60fps** even on budget phones, stick to **compositor-only properties**: `transform` and `opacity`.

<DoDont
  doTitle="Animate transform & opacity (Fast)"
  dontTitle="Avoid Animating Layout Properties"
  doCode={`.card {
  transition: transform 200ms ease, box-shadow 200ms ease;
}
.card:hover {
  transform: translateY(-4px);
}`}
  dontCode={`/* Triggers layout recalculation every frame! */
.card {
  transition: all 200ms ease;
}
.card:hover {
  margin-top: -4px;
}`}
  note="Avoid transition: all, explicitly listing the properties you animate prevents accidental jank."
/>

<Callout type="tip" title="Modern Individual Transform Properties">
  Modern CSS lets you write <code>translate: 0 -4px;</code>, <code>scale: 1.03;</code>, and <code>rotate: 2deg;</code> as standalone properties without overwriting each other!
</Callout>
