**Flexbox** (`display: flex`) is designed for laying out items in **one dimension**, either a horizontal row or a vertical column.

## The Three Properties You'll Use Daily

| Property | What it controls | Common values |
| :--- | :--- | :--- |
| `justify-content` | Alignment along the **main axis** | `flex-start`, `center`, `space-between` |
| `align-items` | Alignment along the **cross axis** | `stretch`, `center`, `flex-start` |
| `gap` | Space between flex items | `8px`, `1rem`, `16px` |

## Try It Yourself

Change `justify-content` from `space-between` to `center` or `flex-end`, or switch `flex-direction` to `column`!
