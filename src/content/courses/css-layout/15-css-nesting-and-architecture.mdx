Two of the biggest upgrades in modern CSS (**Native Nesting** and **Cascade Layers (`@layer`)**)let you write clean, scalable stylesheets without Sass or `!important`.

## Native CSS Nesting

Group child rules, hover states, and media queries right inside the parent selector:

```css
.course-pill {
  background: #eff6ff;
  color: #1d4ed8;

  &:hover {
    background: #dbeafe;
  }

  & strong {
    font-weight: 800;
  }
}
```

## Cascade Layers (`@layer`)

Declare your layer order once at the top of your stylesheet:

```css
@layer reset, components, utilities;
```

Rules in a **later layer** (`utilities`) *always* beat rules in an **earlier layer** (`components`), even if the earlier layer used a more specific selector!

<Callout type="tip" title="Tailwind CSS v4 Uses @layer Under the Hood">
  SkillForge itself runs on Tailwind CSS v4, which relies on native <code>@layer</code> so utility classes override component styles cleanly without specificity battles.
</Callout>

## Try It Yourself

Notice how `.btn-highlight` in `@layer utilities` overrides `button.primary` in `@layer components` cleanly!

<Playground
  client:visible
  title="Native CSS Nesting + @layer"
  defaultTab="css"
  height={250}
  html={`<div class="box">
  <button class="primary">Component Button</button>
  <button class="primary bg-emerald">Utility Layer Override</button>
</div>`}
  css={`@layer components, utilities;

@layer components {
  .box {
    display: flex;
    gap: 10px;

    & button.primary {
      background: #2563eb;
      color: white;
      border: none;
      padding: 10px 16px;
      border-radius: 10px;
      font-weight: 600;
      cursor: pointer;

      &:hover {
        filter: brightness(1.08);
      }
    }
  }
}

@layer utilities {
  .bg-emerald {
    background: #059669;
  }
}`}
/>
