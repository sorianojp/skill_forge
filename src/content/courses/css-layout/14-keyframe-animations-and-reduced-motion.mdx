While `transition` animates between two states (e.g., default → hover), **`@keyframes`** lets you choreograph multi-step or looping animations automatically.

## Respecting `prefers-reduced-motion`

Motion that feels playful to some users can trigger dizziness or nausea for people with vestibular disorders. Always guard decorative or looping motion with a media query:

```css
@media (prefers-reduced-motion: reduce) {
  .pulse, .spinner {
    animation: none;
  }
}
```

<Callout type="warning" title="Accessibility Requirement">
  Treating <code>prefers-reduced-motion: reduce</code> as a standard part of every animation guarantees a comfortable experience for all learners.
</Callout>
