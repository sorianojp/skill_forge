CSS `position` lets you take elements out of normal document flow or keep them pinned while scrolling.

| Value | Behavior | Best Use Case |
| :--- | :--- | :--- |
| `relative` | Stays in flow; creates an anchor for `absolute` children | Card containers holding corner badges |
| `absolute` | Positioned relative to the nearest positioned ancestor | Notification dots, close buttons, tags |
| `sticky` | Scrolls normally until hitting an edge (`top: 0`), then sticks | Navigation bars, table headers, TOC sidebars |
| `fixed` | Pinned to the viewport regardless of scroll | Floating help buttons, persistent banners |

<Callout type="warning" title="Why isn't my position: sticky working?">
  Two classic causes: (1) You forgot to set a threshold like <code>top: 0</code>, or (2) an ancestor element has <code>overflow: hidden</code> instead of <code>overflow: clip</code>.
</Callout>
