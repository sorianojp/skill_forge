Modern CSS gives you built-in design-token variables and dynamic color functions, no preprocessor required.

## CSS Custom Properties (`--vars`)

Declare variables on `:root` and read them anywhere with `var(--name, fallback)`:

```css
:root {
  --brand: #2563eb;
  --radius: 0.75rem;
}
.button {
  background: var(--brand);
  border-radius: var(--radius);
}
```

## Choosing the Right CSS Units

| Unit | Relative To | Best Used For |
| :--- | :--- | :--- |
| `rem` | Root `<html>` font size (usually 16px) | Font sizes, spacing (respects user zoom settings!) |
| `ch` | Width of the `"0"` character | Comfortable paragraph line lengths (`max-width: 65ch`) |
| `dvh` | Dynamic mobile viewport height | Full-screen heroes without mobile address-bar cutoff |
| `%` | Parent container dimension | Fluid widths |

<Callout type="tip" title="Dynamic Tints with color-mix()">
  Generate a soft hover background from a single brand variable using <code>color-mix(in srgb, var(--brand) 15%, white)</code>!
</Callout>

## Try It Yourself

Change `--brand` in `:root` from `#2563eb` to `#7c3aed` or `#059669` and watch the entire card theme update automatically!

<Playground
  client:visible
  title="One-Token Theme with color-mix()"
  defaultTab="css"
  height={260}
  html={`<div class="card">
  <span class="tag">Design Token</span>
  <h3>Change --brand to re-theme!</h3>
  <p>Borders, soft backgrounds, and buttons all derive from one CSS variable.</p>
  <button>Get Started</button>
</div>`}
  css={`:root {
  --brand: #2563eb;
}
.card {
  max-width: 42ch;
  padding: 1.25rem;
  border-radius: 0.85rem;
  border: 1px solid color-mix(in srgb, var(--brand) 30%, white);
  background: color-mix(in srgb, var(--brand) 7%, white);
}
.tag {
  display: inline-block;
  font-size: 0.75rem;
  font-weight: 700;
  color: var(--brand);
  background: color-mix(in srgb, var(--brand) 16%, white);

  background: var(--brand);
  color: white;
  border: none;
  padding: 0.55rem 1rem;
  border-radius: 0.5rem;
  font-weight: 600;
  cursor: pointer;
}`}
/>
