Every HTML element is a rectangular box made of four layers from the inside out: **Content → Padding → Border → Margin**.

## Always Reset `box-sizing`

By default (`content-box`), adding `padding: 20px` to a `width: 200px` box makes it `240px` wide! Switching to `border-box` keeps the total width locked at `200px`.

<DoDont
  doTitle="Predictable Sizing"
  dontTitle="Default Surprise Overflow"
  doCode={`*, *::before, *::after {
  box-sizing: border-box;
}
.card {
  width: 240px;
  padding: 20px; /* stays 240px */
}`}
  dontCode={`.card {
  box-sizing: content-box;
  width: 240px;
  padding: 20px; /* becomes 280px! */
}`}
/>

## Fluid Sizing with `clamp()`

Instead of jumping font sizes at 4 different breakpoints, `clamp(min, preferred, max)` scales smoothly:

```css
h1 {
  font-size: clamp(1.25rem, 4vw, 2.25rem);
}
```
