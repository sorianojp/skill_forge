Modern CSS selectors eliminate dozens of JavaScript helper classes.

## The `:has()` "Parent Selector"

Want to highlight a card *only when* the checkbox inside it is checked, with **zero JavaScript**?

```css
.plan-card:has(input:checked) {
  border-color: #2563eb;
  background: #eff6ff;
}
```

## `:is()` vs. `:where()`

Both simplify repetitive selector lists like `:is(h1, h2, h3) a { ... }`, with one key difference:
- **`:is(...)`** takes the specificity of its *most specific* argument.
- **`:where(...)`** always has **zero specificity `(0, 0, 0)`**, making it ideal for base/reset styles that are easy to override!

<Callout type="tip" title="Zero-JS Interactive Cards">
  Combine <code>:has(input:checked)</code> with native checkboxes or radio buttons to build selectable pricing tiers, filters, and checklists without writing a single line of JavaScript.
</Callout>
