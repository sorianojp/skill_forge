Frameworks like Express, Fastify, and Hono all build on top of Node's built-in **`node:http`** module. Understanding `req.method`, `req.url`, `res.writeHead(status, headers)`, and `res.end(body)` demystifies every Node web framework.

<Callout type="tip" title="Standard HTTP Status Codes">
  <code>200 OK</code> for reads, <code>201 Created</code> for new resources, <code>400 Bad Request</code> for invalid input, <code>401 Unauthorized</code> for missing auth, and <code>404 Not Found</code> for unknown routes.
</Callout>

## Live Code Lab (Node.js 20)

<CodeLab
  client:visible
  title="router_demo.js"
  language="node"
  code={`function handleRequest(method, rawUrl) {
  const url = new URL(rawUrl, "http://localhost");
  if (method === "GET" && url.pathname === "/api/courses") {
    const track = url.searchParams.get("track") ?? "all";
    return { status: 200, body: { filter: track, ok: true } };
  }
  return { status: 404, body: { error: "Not found" } };
}

console.log(handleRequest("GET", "/api/courses?track=node"));
console.log(handleRequest("GET", "/api/unknown"));`}

{ status: 404, body: { error: 'Not found' } }`}
