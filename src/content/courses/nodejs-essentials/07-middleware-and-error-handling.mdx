**Middleware** is a chain of functions `(req, res, next)` that run before your route handler: logging request timing, parsing JSON bodies, verifying auth tokens, and catching thrown errors in one central place.

<Callout type="warning" title="Never Leak Stack Traces in Production">
  Log full error stacks on the server, but return a clean JSON error like <code>&#123; "error": "Internal server error" &#125;</code> to external HTTP callers.
</Callout>

## Live Code Lab (Node.js 20)

<CodeLab
  client:visible
  title="middleware.js"
  language="node"
  code={`function runPipeline(req, middlewares) {
  let idx = 0;
  function next() {
    const fn = middlewares[idx++];
    if (fn) fn(req, next);
  }
  next();
}

const logMw = (req, next) => { console.log("-> " + req.method + " " + req.path); next(); };
const authMw = (req, next) => {
  if (!req.token) return console.log("401 Unauthorized");
  next();
};
const handler = (req) => console.log("200 OK for user:", req.token);

runPipeline({ method: "GET", path: "/api/progress", token: "valid" }, [logMw, authMw, handler]);
runPipeline({ method: "GET", path: "/api/progress" }, [logMw, authMw, handler]);`}
  expectedOutput={`-> GET /api/progress
200 OK for user: valid
-> GET /api/progress
401 Unauthorized`}
/>
