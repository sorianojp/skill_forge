Never interpolate user input into a SQL string (`"SELECT * FROM users WHERE email = '" + email + "'"`). Always pass placeholders (`$1` in Postgres, `?` in SQLite/MySQL) with a separate values array so the database engine treats input strictly as **data**, never executable SQL.

<Callout type="tip" title="Select Only the Columns You Need">
  Prefer <code>SELECT id, name, email FROM users</code> over <code>SELECT *</code> so sensitive fields like <code>password_hash</code> are never accidentally serialized into JSON responses.
</Callout>
