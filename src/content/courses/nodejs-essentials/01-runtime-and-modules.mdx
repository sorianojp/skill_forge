**Node.js** executes JavaScript on the server using Chrome's V8 engine and an asynchronous, event-driven I/O model (`libuv`). Because JavaScript runs on a single main thread, keeping I/O asynchronous lets one Node process serve thousands of concurrent connections.

<Callout type="tip" title="Always Prefix Built-Ins with node:">
  Writing <code>require('node:path')</code> or <code>import path from 'node:path'</code> makes it explicit that you are importing a built-in Node module, not an npm package.
</Callout>
