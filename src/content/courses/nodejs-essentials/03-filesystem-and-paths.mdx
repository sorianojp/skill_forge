The **`node:fs/promises`** module provides modern Promise-based file operations (`readFile`, `writeFile`, `mkdir`, `readdir`) that pair cleanly with `async` / `await`.

<Callout type="warning" title="Always Sanitize User-Supplied File Paths">
  Never pass raw request parameters like <code>req.query.file</code> directly to <code>readFile()</code> without validating against path traversal (<code>../../etc/passwd</code>).
</Callout>

## Live Code Lab (Node.js 20)

<CodeLab
  client:visible
  title="fs_demo.js"
  language="node"
  code={`const fs = require("node:fs/promises");

async function main() {
  const payload = { app: "SkillForge", tracks: 18 };
  await fs.writeFile("/tmp/sf_node.json", JSON.stringify(payload), "utf8");

  const raw = await fs.readFile("/tmp/sf_node.json", "utf8");
  const parsed = JSON.parse(raw);
  console.log("Loaded:", parsed.app, "| Tracks:", parsed.tracks);
}

main();`}
  expectedOutput={`Loaded: SkillForge | Tracks: 18`}
/>
