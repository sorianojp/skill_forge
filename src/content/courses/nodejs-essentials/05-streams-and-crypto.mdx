Reading a 2 GB log file with `fs.readFile()` loads all 2 GB into RAM at once. **Streams** process chunks (typically 64 KB at a time) using constant memory. Meanwhile, **`node:crypto`** gives you built-in SHA-256 hashing, HMAC signatures, and secure random token generation (`crypto.randomUUID()`).

<Callout type="warning" title="Never Use Math.random() for Tokens">
  <code>Math.random()</code> is predictable and unsafe for session IDs or password resets. Always use <code>crypto.randomBytes(32).toString('hex')</code> or <code>crypto.randomUUID()</code>.
</Callout>
