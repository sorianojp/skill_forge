Node.js 20 ships with a **built-in test runner** (`node:test`) and strict assertions (`node:assert/strict`). For backend utilities and APIs, you can run fast automated tests with `node --test` and zero `node_modules` bloat.

<Callout type="tip" title="Always Use node:assert/strict">
  <code>assert.equal</code> in strict mode uses <code>Object.is</code> (like <code>===</code>), preventing subtle JavaScript coercion bugs like <code>"1" == 1</code>.
</Callout>

<CodeLab
  client:visible
  title="assert_demo.js"
  language="node"
  code={`const assert = require("node:assert/strict");

function passRate(passed, total) {
  return total === 0 ? 0 : Math.round((passed / total) * 100);
}

assert.equal(passRate(8, 10), 80);
assert.equal(passRate(0, 0), 0);
console.log("All 2 assertions passed!");`}
