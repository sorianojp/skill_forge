In Node.js, **Promise callbacks (microtasks)** always drain immediately after the current call stack finishes, *before* the next timer (`setTimeout`) callback runs.

<Callout type="tip" title="Avoid Sequential await Waterfalls">
  If two database or HTTP calls do not depend on each other, run them together with <code>await Promise.all([a(), b()])</code> instead of awaiting them one after another.
</Callout>
