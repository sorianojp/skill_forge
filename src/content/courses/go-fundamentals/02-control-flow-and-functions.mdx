## Overview

Use Go's single loop keyword `for`, `if` with init statements, `switch` without fallthrough, and multiple return values.

Go prioritizes simplicity, explicit control flow, fast compilation, and safe concurrency. Every feature in this lesson is part of Go's minimal standard toolkit used across cloud infrastructure, CLI tools, and high-throughput APIs.

## Idiomatic Go Example

```go
package main

import "fmt"

func divide(a, b int) (int, bool) {
    if b == 0 {
        return 0, false
    }
    return a / b, true
}

func main() {
    if q, ok := divide(20, 4); ok {
        fmt.Println("Quotient:", q)
    }
}
```
