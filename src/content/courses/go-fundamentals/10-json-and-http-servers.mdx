## Overview

Build fast, dependency-free HTTP servers with Go's standard net/http router and encoding/json struct tags.

Go prioritizes simplicity, explicit control flow, fast compilation, and safe concurrency. Every feature in this lesson is part of Go's minimal standard toolkit used across cloud infrastructure, CLI tools, and high-throughput APIs.

## Idiomatic Go Example

```go
package main

import (
    "encoding/json"
    "fmt"
)

type Course struct {
    Slug  string `json:"slug"`
    Hours int    `json:"hours"`
}

func main() {
    b, _ := json.Marshal(Course{Slug: "go-fundamentals", Hours: 6})
    fmt.Println(string(b))
}
```
