## Overview

Write idiomatic table-driven unit tests with testing.T and measure allocations with testing.B benchmarks.

Go prioritizes simplicity, explicit control flow, fast compilation, and safe concurrency. Every feature in this lesson is part of Go's minimal standard toolkit used across cloud infrastructure, CLI tools, and high-throughput APIs.

## Idiomatic Go Example

```go
package mathutil

import "testing"

func TestAdd(t *testing.T) {
    cases := []struct{ a, b, want int }{{2, 3, 5}, {-1, 1, 0}}
    for _, tc := range cases {
        if got := tc.a + tc.b; got != tc.want {
            t.Fatalf("got %d, want %d", got, tc.want)
        }
    }
}
```
