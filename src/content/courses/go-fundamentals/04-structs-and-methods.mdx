## Overview

Model domain entities with structs and choose between value receivers and pointer receivers on methods.

Go prioritizes simplicity, explicit control flow, fast compilation, and safe concurrency. Every feature in this lesson is part of Go's minimal standard toolkit used across cloud infrastructure, CLI tools, and high-throughput APIs.

## Idiomatic Go Example

```go
package main

import "fmt"

type Counter struct {
    Value int
}

func (c *Counter) Increment() {
    c.Value++
}

func main() {
    c := Counter{Value: 1}
    c.Increment()
    fmt.Println(c.Value)
}
```
