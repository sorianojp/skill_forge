## Overview

Handle errors as explicit return values, wrap context with fmt.Errorf %w, inspect with errors.Is, and clean up with defer.

Go prioritizes simplicity, explicit control flow, fast compilation, and safe concurrency. Every feature in this lesson is part of Go's minimal standard toolkit used across cloud infrastructure, CLI tools, and high-throughput APIs.

## Idiomatic Go Example

```go
package main

import (
    "errors"
    "fmt"
)

var ErrEmpty = errors.New("empty input")

func validate(s string) error {
    if s == "" {
        return fmt.Errorf("validate failed: %w", ErrEmpty)
    }
    return nil
}
```
