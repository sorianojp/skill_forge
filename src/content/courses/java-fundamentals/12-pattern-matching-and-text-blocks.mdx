Java 21 eliminates verbose `instanceof` casts with **pattern matching**: `if (obj instanceof String s)` tests the type *and* binds `s` in one step, and `switch` can match directly on types and guarded conditions (`case String s when !s.isBlank() -> ...`).

<Callout type="tip" title="Text Blocks Keep JSON & SQL Readable">
  Triple quotes (<code>"""</code>) preserve indentation cleanly without cluttered <code>\n</code> and <code>\"</code> escapes.
</Callout>

## Live Code Lab

<CodeLab
  client:visible
  title="PatternsJava21.java"
  language="java"
  code={`public class PatternsJava21 {
    static String describe(Object obj) {
        return switch (obj) {
            case Integer i -> "Int: " + (i * 2);
            case String s -> "Text(" + s.length() + "): " + s;
            case null -> "Null";
            default -> "Other";
        };
    }

    public static void main(String[] args) {
        System.out.println(describe(21));
        System.out.println(describe("DevPath"));
    }
}`}
