The **Java Collections Framework** (`List`, `Set`, `Map`) paired with the **Streams API** lets you express data pipelines cleanly without mutable temporary lists.

## Streams & `Optional`

- `list.stream().filter(...).map(...).toList()` builds a clean transformation pipeline.
- `Optional<T>` signals explicitly that a lookup might return no value, encouraging safe handling with `.orElse(...)` instead of risking a `NullPointerException`.

<Callout type="tip" title="List.of() Creates Unmodifiable Lists">
  <code>List.of("Java", "C#")</code> is concise and immutable. If you need to add or remove items later, wrap it in <code>new ArrayList&lt;&gt;(...)</code>.
</Callout>

## Interactive Code Lab

<CodeLab
  client:visible
  title="StreamsDemo.java"
  language="java"
  code={`import java.util.List;

public class StreamsDemo {
    public static void main(String[] args) {
        var scores = List.of(72, 88, 95, 64, 91);

        var topScores = scores.stream()
            .filter(s -> s >= 85)
            .sorted()
            .toList();

        var firstPerfect = scores.stream()
            .filter(s -> s == 100)
            .findFirst()
            .orElse(0);

        System.out.println("Top scores: " + topScores);
        System.out.println("Perfect found: " + firstPerfect);
    }
}`}
  expectedOutput={`Top scores: [88, 91, 95]
Perfect found: 0`}
