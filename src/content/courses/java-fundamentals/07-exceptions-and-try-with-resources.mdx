In Java, any resource implementing `AutoCloseable` (files, database connections, HTTP streams) should be opened inside **`try (var res = ...)`**. Java automatically invokes `res.close()` when the block finishes, even if an exception is thrown.

<Callout type="tip" title="Never Swallow Exceptions Silently">
  An empty <code>catch (Exception e) &#123;&#125;</code> hides bugs. Always log, wrap, or handle the failure explicitly.
</Callout>

    static int parsePositive(String raw) {
        int val = Integer.parseInt(raw);
        if (val <= 0) throw new IllegalArgumentException("Must be > 0");
        return val;
    }

    public static void main(String[] args) {
        try {
            System.out.println("Parsed: " + parsePositive("42"));
            System.out.println(parsePositive("-3"));
        } catch (IllegalArgumentException e) {
            System.out.println("Handled: " + e.getMessage());
        }
    }
}`}
