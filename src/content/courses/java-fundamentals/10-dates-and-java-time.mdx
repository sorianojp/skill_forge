Always use the **`java.time`** package (`LocalDate`, `LocalDateTime`, `ZonedDateTime`, `Instant`). Unlike the old mutable `java.util.Date`, every `java.time` class is **immutable** and thread-safe.

<Callout type="tip" title="Store Instant (UTC) in Databases">
  Keep timestamps in UTC using <code>Instant.now()</code> on the backend, and format them to the user's local timezone only at display time.
</Callout>

## Live Code Lab

<CodeLab
  client:visible
  title="TimeDemo.java"
  language="java"
  code={`import java.time.LocalDate;
import java.time.temporal.ChronoUnit;

public class TimeDemo {
    public static void main(String[] args) {
        var start = LocalDate.of(2026, 11, 1);
        var deadline = start.plusDays(14);
        long days = ChronoUnit.DAYS.between(start, deadline);

        System.out.println("Start: " + start + " | Deadline: " + deadline + " (" + days + " days)");
    }
}`}
  expectedOutput={`Start: 2026-11-01 | Deadline: 2026-11-15 (14 days)`}
