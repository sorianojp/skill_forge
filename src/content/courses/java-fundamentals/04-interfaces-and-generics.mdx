In Java, a class can extend only one parent class, but it can implement **many interfaces**. Interfaces let you decouple callers from concrete implementations and make unit testing straightforward.

## Generics (`<T>`)

**Generics** let classes like `List<String>` or `Repository<User>` enforce element types at compile time, eliminating unsafe runtime casts.

<Callout type="info" title="Always Use @Override">
  Putting <code>@Override</code> above interface or superclass methods makes the compiler fail immediately if you misspell a method name or change a parameter type.
</Callout>
