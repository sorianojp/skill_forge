Modern Java (14+) introduced **switch expressions** using arrow syntax (`->`). Unlike legacy `switch` statements, arrow cases never fall through and can return a value directly into a variable.

## Enhanced For-Each Loop

When you do not need the array index, `for (int n : scores)` is cleaner and eliminates index-out-of-bounds bugs.

<Callout type="tip" title="Exhaustive Switch Expressions">
  When a <code>switch</code> expression returns a value, the Java compiler verifies that every possible case (or a <code>default</code> branch) is handled.
</Callout>

## Interactive Code Lab

<CodeLab
  client:visible
  title="ControlFlow.java"
  language="java"
  code={`public class ControlFlow {
    static String gradeLabel(int score) {
        return switch (score / 10) {
            case 10, 9 -> "A";
            case 8 -> "B";
            case 7 -> "C";
            default -> "Review";
        };
    }

    public static void main(String[] args) {
        int[] scores = {94, 82, 75};
        for (int s : scores) {
            System.out.println(s + " -> " + gradeLabel(s));
        }
    }
}`}
  expectedOutput={`94 -> A
82 -> B
75 -> C`}
/>
