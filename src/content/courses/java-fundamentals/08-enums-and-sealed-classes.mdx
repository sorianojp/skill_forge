Java **`enum`** types are full classes: each constant can hold fields and methods. Modern Java also adds **`sealed interface`**, letting you declare the exact closed set of permitted subtypes so the compiler guarantees your `switch` handles every case.

<Callout type="info" title="No Default Needed When Exhaustive">
  When switching over an <code>enum</code> or <code>sealed</code> hierarchy with every case covered, you do not need a <code>default</code> branch, and adding a new subtype immediately flags every switch that needs updating.
</Callout>

## Live Code Lab

<CodeLab
  client:visible
  title="EnumsDemo.java"
  language="java"
  code={`public class EnumsDemo {
    enum Plan {
        FREE(0), PRO(19), TEAM(49);
        final int monthlyUsd;
        Plan(int monthlyUsd) { this.monthlyUsd = monthlyUsd; }
    }

    public static void main(String[] args) {
        for (Plan p : Plan.values()) {
            System.out.println(p + ": $" + p.monthlyUsd + "/mo");
        }
    }
}`}
