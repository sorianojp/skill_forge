**Java** is a strongly typed, object-oriented language that compiles to JVM bytecode and runs everywhere, from high-throughput Spring Boot microservices to Android apps.

## Primitives vs. Reference Types

- **Primitives** (`int`, `long`, `double`, `boolean`, `char`) store values directly.
- **Reference types** (`String`, `List`, custom classes) store object references. Always compare `String` values with `.equals()`, because `==` compares memory references, not text content.

<Callout type="warning" title="Always Use .equals() for Strings">
  <code>a.equals(b)</code> checks whether two Strings contain the same characters. Using <code>==</code> on Strings can return <code>false</code> even when the text is identical.
</Callout>
