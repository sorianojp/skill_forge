**`HashMap<K, V>`** and **`HashSet<T>`** provide average $O(1)$ lookups. Modern Java adds convenience methods like `getOrDefault(key, 0)` and `merge(key, 1, Integer::sum)` that replace verbose `if (map.containsKey(...))` blocks.

<Callout type="tip" title="Always Pair equals() and hashCode()">
  If you use a custom class as a <code>HashMap</code> key, make sure it overrides both <code>equals()</code> and <code>hashCode()</code> (Java <code>record</code> types do this automatically!).
</Callout>

## Live Code Lab

<CodeLab
  client:visible
  title="MapDemo.java"
  language="java"
  code={`import java.util.*;

public class MapDemo {
    public static void main(String[] args) {
        var tags = List.of("java", "oop", "java", "streams", "java");
        var counts = new HashMap<String, Integer>();
        for (var t : tags) {
            counts.merge(t, 1, Integer::sum);
        }
        System.out.println("java count: " + counts.getOrDefault("java", 0));
        System.out.println("unique tags: " + new TreeSet<>(tags));
    }
}`}
  expectedOutput={`java count: 3
unique tags: [java, oop, streams]`}
/>
