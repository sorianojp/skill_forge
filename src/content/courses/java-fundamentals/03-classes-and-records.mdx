Traditional Java classes required dozens of lines for constructors, getters, `equals()`, `hashCode()`, and `toString()`. Modern Java solves this with **`record`**: a single line declares an immutable data carrier with all of those generated automatically.

## Class vs. Record

- Use **`record`** for immutable data (API DTOs, coordinates, configuration, events).
- Use **`class`** when an entity owns mutable state or complex lifecycle behavior.

<Callout type="tip" title="Compact Constructors for Validation">
  You can add validation right inside a <code>record</code> without repeating field assignments, throwing <code>IllegalArgumentException</code> if an invariant is broken.
</Callout>

## Interactive Code Lab

<CodeLab
  client:visible
  title="RecordsDemo.java"
  language="java"
  code={`public class RecordsDemo {
    public record Course(String title, int lessons) {
        public Course {
            if (lessons <= 0) {
                throw new IllegalArgumentException("lessons must be > 0");
            }
        }
    }

    public static void main(String[] args) {
        var c = new Course("Java 21 Essentials", 6);
        System.out.println(c);
        System.out.println("Title: " + c.title());
    }
}`}
  expectedOutput={`Course[title=Java 21 Essentials, lessons=6]
Title: Java 21 Essentials`}
