## Overview

Compute rankings, top-N per group, running totals, and moving averages without collapsing rows via OVER (PARTITION BY ...).

Strong database design pays dividends for years: clean constraints catch bugs before application code does, and well-chosen indexes keep response times predictable as tables grow from thousands to millions of rows.

## Key Takeaways

- **Distinguish GROUP BY aggregation from window functions**
- **Use ROW_NUMBER(), RANK(), and DENSE_RANK()**
- **Calculate running totals with SUM() OVER (ORDER BY ...)**
