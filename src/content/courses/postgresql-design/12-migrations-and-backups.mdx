## Overview

Evolve live production schemas safely using expand-and-contract migrations, concurrent index builds, and tested backups.

Strong database design pays dividends for years: clean constraints catch bugs before application code does, and well-chosen indexes keep response times predictable as tables grow from thousands to millions of rows.

<Callout type="note" title="PostgreSQL Production Tip">
Always inspect realistic table sizes with `EXPLAIN (ANALYZE, BUFFERS)` before assuming an index is being used. Small tables often prefer sequential scans because reading one memory page is faster than traversing a tree.
