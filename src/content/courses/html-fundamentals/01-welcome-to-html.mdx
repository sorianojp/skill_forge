HTML (**HyperText Markup Language**) gives a web page its **meaning and structure**. Every site you visit (from simple blogs to complex web apps)starts with HTML.

## Anatomy of an HTML Element

Most HTML elements have three parts:

1. **Opening tag**: e.g., `<p>`
2. **Content**: the text or nested elements inside
3. **Closing tag**: e.g., `</p>`

```html
<a href="https://skillforge.dev">Start learning</a>
```

In the example above, `href` is an **attribute** that tells the browser where the link points.

## Heading Hierarchy Matters

Use `<h1>` for the main page title, `<h2>` for major sections, and `<h3>` for subsections. Never pick a heading tag just because you like its default font size, use CSS for visual sizing.
