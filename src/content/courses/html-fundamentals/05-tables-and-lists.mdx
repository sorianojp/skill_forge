HTML provides purpose-built elements for structured data and collapsible FAQs, no JavaScript frameworks needed.

## Accessible Data Tables

Use `<table>` strictly for **tabular data** (schedules, pricing comparisons, metrics), never for page layout.

Key accessibility ingredients:
- **`<caption>`**: Acts like a title for the table.
- **`<thead>` and `<tbody>`**: Separate column headers from data rows.
- **`<th scope="col">` / `<th scope="row">`**: Explicitly links headers to their cells for screen readers.

## Native Accordions with `<details>` & `<summary>`

Need an FAQ or collapsible hint? Native HTML `<details>` works with keyboard navigation and screen readers out of the box!

<Callout type="tip" title="Linked Exclusive Accordions">
  Give multiple <code>&lt;details&gt;</code> elements the same <code>name="faq"</code> attribute, and opening one automatically closes the others, with zero JavaScript!
</Callout>
