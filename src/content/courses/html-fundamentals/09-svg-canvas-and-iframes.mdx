HTML gives you two native graphics engines (**`<svg>`** and **`<canvas>`**)plus **`<iframe>`** for embedding isolated documents (like the live code previews on SkillForge!).

## `<svg>` vs. `<canvas>`

| Feature | `<svg>` (Vector) | `<canvas>` (Raster / Pixels) |
| :--- | :--- | :--- |
| Scaling | Infinitely sharp at any zoom | Pixelates if stretched without HiDPI scaling |
| DOM & CSS | Each shape is a DOM node (styleable & accessible) | Single bitmap element drawn via JS |
| Best for | Icons, logos, UI diagrams, simple charts | Games, photo editors, thousands of animated particles |

## Safe `<iframe>` Embeds

Always give every `<iframe>` two things:
1. **`title="..."`**: Required so screen-reader users know what the embedded frame contains.
2. **`sandbox`**: Restricts scripts, popups, and top-level navigation unless explicitly opted in (e.g., `sandbox="allow-scripts"`).

<Callout type="warning" title="Iframe Security">
  Never combine <code>allow-scripts</code> and <code>allow-same-origin</code> on untrusted third-party content, that lets the embedded script remove its own sandbox attribute!
</Callout>
