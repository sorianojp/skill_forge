Forms are how users sign up, search, and interact with your site. Well-built HTML forms give you **accessibility, mobile keyboard optimization, and validation for free**.

## Always Pair `<label>` with `<input>`

Never rely on `placeholder` text as a replacement for a `<label>`. Placeholders disappear as soon as the user starts typing and are harder to read.

<Callout type="warning" title="Click-Target Bonus">
  When a <code>&lt;label for="email"&gt;</code> is linked to <code>&lt;input id="email"&gt;</code>, clicking the label automatically focuses the input, making forms much easier to use on touchscreens.
</Callout>

## Try It Yourself

Try submitting the form empty or with an invalid email to see native browser validation in action:

<Playground
  client:visible
  title="Accessible Signup Form"
  height={300}
  html={`<form id="signup" class="form">
  <div class="field">
    <label for="name">Full Name</label>
    <input id="name" name="name" type="text" required minlength="2" placeholder="Ada Lovelace" />
  </div>

  <div class="field">
    <label for="email">Email Address</label>
    <input id="email" name="email" type="email" required placeholder="ada@example.com" />
  </div>

  <button type="submit">Join Free Course</button>
  <p id="status" role="status"></p>
</form>`}
  css={`.form { max-width: 340px; display: grid; gap: 12px; }
.field { display: grid; gap: 4px; }
label { font-size: 13px; font-weight: 600; color: #334155; }

  padding: 8px 10px;
  border: 1px solid #cbd5e1;
  border-radius: 8px;
  font-size: 14px;
}
button {
  background: #2563eb;
  color: white;
  border: none;
  border-radius: 8px;
  padding: 10px 14px;
  font-weight: 600;
  cursor: pointer;
}

});`}
