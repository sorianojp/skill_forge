**Semantic HTML** means choosing the HTML element that accurately describes *what the content is*, not just how it looks.

## Why Semantics Matter

- **Accessibility:** Screen readers let users jump directly to `<main>`, `<nav>`, or `<article>` landmarks.
- **SEO:** Search engines understand which part of your page is the primary content vs. navigation or footer boilerplate.
- **Maintainability:** Reading `<header>` and `<article>` is far clearer than reading ten nested `<div>` tags.

<DoDont
  doTitle="Use Semantic Landmarks"
  dontTitle="Avoid Div Soup"
  doCode={`<header>
  <nav>...</nav>
</header>
<main>
  <article>
    <h1>Lesson Title</h1>
    <p>Readable content...</p>
  </article>
</main>
<footer>© DevPath</footer>`}
  dontCode={`<div class="top">
  <div class="links">...</div>
</div>
<div class="content">
  <div class="post">
    <div class="big-text">Lesson Title</div>
    <div>Readable content...</div>
  </div>
</div>
<div class="bottom">© DevPath</div>`}
  note="Prefer native interactive elements too: use <button> for actions and <a> for navigation, never clickable <div> elements."
/>

## Try It Yourself

Explore how semantic elements create a clean, readable document skeleton:

<Playground
  client:visible
  title="Semantic Page Layout"
  height={280}
  html={`<header class="site-header">
  <strong>DevPath Blog</strong>
  <nav aria-label="Main">
    <a href="#article">Article</a>
    <a href="#footer">Footer</a>
  </nav>
</header>

<main id="article">
  <article>
    <h1>Why Semantic HTML Wins</h1>
    <p>Browsers, assistive tech, and search engines all benefit from clear HTML landmarks.</p>
  </article>
</main>

<footer id="footer">
  <small>Built with semantic HTML.</small>
</footer>`}
  css={`.site-header {
  display: flex;
  justify-content: space-between;
  align-items: center;
  padding: 10px 14px;
  background: #eff6ff;
  border-radius: 10px;
}
nav { display: flex; gap: 12px; }
nav a { color: #1d4ed8; font-weight: 600; text-decoration: none; }
main { margin: 16px 0; }
footer { border-top: 1px solid #e2e8f0; padding-top: 10px; color: #64748b; }`}
/>
