HTML offers rich inline elements that carry real meaning, far beyond just making text bold or italic.

## Block vs. Inline Elements

- **Block elements** (`<p>`, `<h1>`–`<h6>`, `<div>`, `<blockquote>`, `<ul>`) start on a new line and stretch to fill the available width.
- **Inline elements** (`<span>`, `<a>`, `<strong>`, `<em>`, `<code>`, `<kbd>`) flow naturally inside a line of text and only take up as much width as their content needs.

## Semantic Inline Text Elements

| Element | Meaning | Example |
| :--- | :--- | :--- |
| `<strong>` | Strong importance / urgency | `<strong>Warning:</strong> Save first.` |
| `<em>` | Verbal stress / emphasis | `I <em>really</em> mean it.` |
| `<mark>` | Highlighted search match or reference | `Match: <mark>HTML</mark>` |
| `<time>` | Machine-readable date or time | `<time datetime="2026-11-25">Nov 25</time>` |
| `<code>` | Inline code snippet | `Use <code>display: grid</code>` |
| `<kbd>` | Keyboard shortcut | `Press <kbd>Ctrl</kbd> + <kbd>K</kbd>` |
| `<abbr>` | Abbreviation with expansion | `<abbr title="HyperText Markup Language">HTML</abbr>` |

## HTML Entities

Because `<`, `>`, and `&` have special meaning in HTML, use **character entities** when you want to display them literally:
- `&lt;` → `<`
- `&gt;` → `>`
- `&amp;` → `&`
- `&copy;` → `©`

<Callout type="note" title="<strong> vs <b> and <em> vs <i>">
  Prefer <code>&lt;strong&gt;</code> and <code>&lt;em&gt;</code> when emphasizing meaning, screen readers can adjust vocal stress for them, whereas <code>&lt;b&gt;</code> and <code>&lt;i&gt;</code> are purely stylistic.
</Callout>
