**Global attributes** can be placed on *any* HTML element. Mastering them gives you clean hooks for CSS styling, JavaScript interactivity, and accessibility.

| Attribute | Purpose | Example |
| :--- | :--- | :--- |
| `id` | **Unique** identifier on the page (links `#anchor`, `<label for>`) | `id="pricing"` |
| `class` | Space-separated reusable names for CSS / JS | `class="btn primary"` |
| `data-*` | Custom app metadata readable via `el.dataset` | `data-course="html"` |
| `hidden` | Hides the element from view and assistive tech | `<div hidden>` |
| `inert` | Disables clicks, focus, and screen-reader access for an entire subtree | `<section inert>` |
| `lang` | Overrides language for a specific word or quote | `<span lang="es">Hola</span>` |

## Boolean Attributes

Attributes like `disabled`, `required`, `hidden`, and `inert` are **boolean attributes**. Their *presence* means `true`, even writing `disabled="false"` still disables the button!

<DoDont
  doTitle="Clean Boolean Attributes"
  dontTitle="Misleading Boolean Values"
  doCode={`<button disabled>Saving...</button>
<input type="checkbox" checked />`}
  dontCode={`<!-- Still disabled! -->
<button disabled="false">Click me</button>`}
/>

<Callout type="tip" title="Modern inert Attribute">
  Adding <code>inert</code> to a container prevents keyboard tabbing, clicks, and text selection inside it, perfect for temporarily locking a form or background panel.
</Callout>
