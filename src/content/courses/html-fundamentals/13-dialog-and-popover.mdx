For years, building an accessible modal required heavy JavaScript libraries to trap focus, dim the background, and handle `Esc`. Today, HTML's native **`<dialog>`** and **`popover`** handle it automatically in the browser's **top layer**!

## Modal `<dialog>` vs. `popover`

- **Use `<dialog>` with `showModal()`** when the overlay **blocks** the rest of the page (confirmations, forms, search palettes). The browser automatically makes the background inert, handles `Esc`, renders `::backdrop`, and returns focus to the button when closed.
- **Use `popover` + `popovertarget`** for non-blocking overlays (dropdown menus, quick info cards, toasts). Clicking outside automatically light-dismisses it, with **zero JavaScript**!

<Callout type="tip" title="Zero-JS Dialog Closing">
  Putting a <code>&lt;form method="dialog"&gt;</code> inside a <code>&lt;dialog&gt;</code> closes the modal automatically when any submit button inside it is clicked, and stores the button's <code>value</code> in <code>dialog.returnValue</code>.
</Callout>

## Try It Yourself

Test both a native **Modal `<dialog>`** (press `Esc` to close!) and a zero-JS **`popover`** below:

<Playground
  client:visible
  title="Native <dialog> Modal + Zero-JS Popover"
