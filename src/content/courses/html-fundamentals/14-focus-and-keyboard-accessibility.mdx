Millions of users navigate the web with a keyboard (`Tab`, `Shift + Tab`, `Enter`, `Space`), whether due to motor disabilities, screen readers, or power-user speed.

## Naturally Focusable Elements

Links (`<a href>`), `<button>`, `<input>`, `<select>`, `<textarea>`, and `<summary>` are **automatically in the keyboard tab order**. Generic `<div>` and `<span>` elements are *not*.

## Understanding `tabindex`

| Value | Meaning | When to Use |
| :--- | :--- | :--- |
| `tabindex="0"` | Adds a non-interactive element to the **natural** DOM tab order | Custom scrollable regions or custom ARIA widgets |
| `tabindex="-1"` | Not reachable via `Tab`, **but** can receive focus via `el.focus()` | Jumping focus to a heading or error summary after form submit |
| `tabindex="1"` (positive) | Forces an element ahead of natural order | **Never use**: breaks predictable tab navigation! |
