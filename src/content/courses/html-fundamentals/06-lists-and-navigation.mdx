## Choosing the Right List

1. **Unordered list (`<ul>`)**: Order doesn't change the meaning (e.g., navigation links, feature bullets).
2. **Ordered list (`<ol>`)**: Sequence matters (e.g., recipe steps, top-5 rankings, breadcrumbs).
3. **Description list (`<dl>`)**: Key-value pairs (`<dt>` term + `<dd>` description), great for glossaries and metadata!

## Accessible Navigation Patterns

- Wrap major link groups in `<nav aria-label="...">`.
- Mark the current page link with **`aria-current="page"`** so screen-reader users immediately know where they are.
- Include a **Skip to content** link (`<a href="#main-content">`) as the very first focusable element on the page so keyboard users can jump past long navbars.

<Callout type="tip" title="Breadcrumbs Use <ol>">
  Because breadcrumb paths represent an ordered hierarchy (Home → Courses → HTML), wrap them in <code>&lt;nav aria-label="Breadcrumb"&gt;&lt;ol&gt;...&lt;/ol&gt;&lt;/nav&gt;</code>.
</Callout>
