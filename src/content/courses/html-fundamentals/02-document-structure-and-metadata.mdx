Every valid HTML page starts with a small, predictable skeleton. Getting `<head>` metadata right ensures your site renders crisply on mobile screens, displays emoji and accents cleanly, and looks great in search results and social shares.

## The Modern HTML5 Boilerplate

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Page Title | DevPath</title>
    <meta name="description" content="A concise 150-character summary for search engines." />
    <link rel="icon" href="/favicon.svg" type="image/svg+xml" />
  </head>
  <body>
    <!-- Visible page content goes here -->
  </body>
</html>
```

### What Each Line Does
- **`<!doctype html>`**: Puts the browser into **standards mode** (avoiding legacy quirks mode).
- **`<html lang="en">`**: Tells screen readers which voice/accent to use and helps search engines and browser translation tools.
- **`<meta charset="UTF-8">`**: Enables full Unicode support (international scripts, punctuation, emoji). Place it as the **first** tag in `<head>`.
- **`<meta name="viewport" ...>`**: Prevents mobile browsers from zooming out your page like a tiny desktop screen.

<Callout type="warning" title="Never Disable Pinch-to-Zoom">
  Avoid adding <code>user-scalable=no</code> or <code>maximum-scale=1</code> to your viewport meta tag, it blocks users with low vision from zooming in and fails WCAG accessibility checks.
</Callout>
