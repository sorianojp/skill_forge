Great forms reduce typing effort and prevent mistakes *before* the user hits submit.

## Grouping Related Inputs with `<fieldset>` & `<legend>`

When you have a group of radio buttons (like "Preferred Track"), wrap them in `<fieldset>` with a `<legend>`. Screen readers automatically announce the legend before each radio option!

## Choosing the Right Control

| Control | Best For |
| :--- | :--- |
| `<input type="radio">` | Choosing **one** option from 2–5 visible choices |
| `<input type="checkbox">` | Toggling **zero or more** independent options |
| `<select>` | Choosing one option from a long list (e.g., country) |
| `<input list="...">` + `<datalist>` | Free-text input with native **autocomplete suggestions** |
| `<textarea>` | Multi-line comments or bio text |

<Callout type="tip" title="Boost Mobile UX with autocomplete">
  Adding standard tokens like <code>autocomplete="name"</code> or <code>autocomplete="email"</code> lets browsers and password managers fill forms in a single tap.
</Callout>
