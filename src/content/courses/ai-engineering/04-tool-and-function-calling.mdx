## Overview

Let LLMs invoke real backend tools (search, SQL lookups, calculators) safely via typed tool declarations.

## Code Example

```ts
const tools = [{
  name: "get_order_status",
  description: "Look up an order status by orderId",
  parameters: { type: "object", properties: { orderId: { type: "string" } }, required: ["orderId"] }
}];
```

<Callout type="tip" title="AI Engineering Habit">
Treat prompts, tool schemas, and retrieval pipelines like production code: version them, validate every output with a schema, and run automated evals before shipping changes.
</Callout>

## Key Takeaways

- **Declare tool names, descriptions, and JSON parameter schemas**
- **Execute requested tools on your server and return structured tool results**
- **Cap maximum tool-call iterations to prevent infinite loops**
