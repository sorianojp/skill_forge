<Callout type="tip" title="AI Engineering Habit">
Treat prompts, tool schemas, and retrieval pipelines like production code: version them, validate every output with a schema, and run automated evals before shipping changes.
</Callout>

## Key Takeaways

- **Route simple classification/extraction to fast lightweight models**
- **Keep static system prompts and shared docs at the prefix for prompt caching**
- **Enforce per-user rate limits and daily token budgets**
