## Overview

Write clear, testable prompts using role clarity, explicit output rules, few-shot examples, and refusal rules.

## Code Example

```ts
const systemPrompt = `Extract invoice fields from the text.
Rules:
1. Return ONLY valid JSON matching { vendor, totalPhp, date }.
2. If a field is missing, set it to null instead of guessing.`;
```

<Callout type="tip" title="AI Engineering Habit">
Treat prompts, tool schemas, and retrieval pipelines like production code: version them, validate every output with a schema, and run automated evals before shipping changes.
</Callout>

## Key Takeaways

- **Replace vague prompts with explicit acceptance criteria**
- **Use 2 to 3 few-shot input/output examples to lock formatting**
- **Instruct the model how to say 'I don't know' when context is missing**
