## Overview

Force type-safe JSON responses using response schemas and validate every model output with Zod or Pydantic.

## Code Example

```ts
import { z } from 'zod';

const TicketSchema = z.object({
  category: z.enum(['billing', 'bug', 'feature']),
  priority: z.enum(['low', 'medium', 'high']),
  summary: z.string().max(140),
});
```

<Callout type="tip" title="AI Engineering Habit">
Treat prompts, tool schemas, and retrieval pipelines like production code: version them, validate every output with a schema, and run automated evals before shipping changes.
</Callout>

## Key Takeaways

- **Attach a JSON Schema / responseSchema directly to the model call**
- **Validate parsed outputs at runtime with Zod or Pydantic**
- **Handle retries gracefully if schema validation fails**
