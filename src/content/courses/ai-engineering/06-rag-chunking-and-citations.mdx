## Overview

Design Retrieval-Augmented Generation pipelines with smart document chunking, overlap, and verifiable inline citations.

## Code Example

```ts
const contextBlock = chunks
  .map((c, i) => `[Source ${i + 1}: ${c.title}]\n${c.text}`)
  .join("\n\n");
```

<Callout type="tip" title="AI Engineering Habit">
Treat prompts, tool schemas, and retrieval pipelines like production code: version them, validate every output with a schema, and run automated evals before shipping changes.
</Callout>

## Key Takeaways

- **Split documents by semantic headings with 10 to 15% overlap**
- **Inject retrieved chunks with source IDs so the model cites exact sources**
- **Measure retrieval recall separately from generation quality**
