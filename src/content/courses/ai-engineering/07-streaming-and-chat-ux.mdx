## Overview

Stream tokens to the browser using Server-Sent Events (SSE) so users see answers in under 500ms.

## Code Example

```ts
const res = new Response(stream, {
  headers: {
    'Content-Type': 'text/event-stream',
    'Cache-Control': 'no-cache',
  },
});
```

## Key Takeaways

- **Measure Time to First Token (TTFT) vs total generation time**
- **Stream chunks via HTTP text/event-stream (SSE)**
- **Support request cancellation with AbortController when users click Stop**
