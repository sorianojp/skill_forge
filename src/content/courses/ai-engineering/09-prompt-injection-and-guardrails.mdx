## Overview

Protect AI apps against prompt injection, data exfiltration, and unauthorized tool actions using least privilege.

## Code Example

```ts
// Always enforce auth on the server, never via prompt text alone
async function deleteRecord(userId: string, recordId: string) {
  return db.query('DELETE FROM items WHERE id = $1 AND owner_id = $2', [recordId, userId]);
}
```

<Callout type="tip" title="AI Engineering Habit">
Treat prompts, tool schemas, and retrieval pipelines like production code: version them, validate every output with a schema, and run automated evals before shipping changes.
</Callout>

## Key Takeaways

- **Treat all user text and retrieved web/PDF chunks as untrusted data**
- **Enforce row-level authorization in tool handlers (never trust the LLM to filter tenant IDs)**
- **Require human confirmation before destructive tool calls (delete, payment, email)**
