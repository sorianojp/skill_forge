## Overview

Understand how LLMs process tokens, system vs user messages, temperature, and context window pricing.

## Code Example

```ts
const payload = {
  model: "gemini-2.5-flash",
  temperature: 0.2,
  messages: [
    { role: "system", content: "You are a concise SQL code reviewer." },
    { role: "user", content: "Review: SELECT * FROM users;" }
  ]
};
```

<Callout type="tip" title="AI Engineering Habit">
Treat prompts, tool schemas, and retrieval pipelines like production code: version them, validate every output with a schema, and run automated evals before shipping changes.
</Callout>

## Key Takeaways

- **Estimate token counts and API cost per 1M input/output tokens**
- **Separate system instructions from untrusted user input**
- **Tune temperature and max_output_tokens for deterministic tasks**
