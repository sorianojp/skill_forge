## Overview

Convert text into dense vector embeddings and retrieve semantically similar documents via cosine similarity.

## Code Example

```ts
-- PostgreSQL pgvector similarity query
SELECT id, title, 1 - (embedding <=> $1::vector) AS similarity
FROM docs
ORDER BY embedding <=> $1::vector
LIMIT 5;
```
