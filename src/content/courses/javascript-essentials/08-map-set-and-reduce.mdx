Plain arrays and objects are great, but JavaScript also includes built-in **`Set`** and **`Map`** collections plus **`.reduce()`** for clean data transformations.

## Instant Deduplication with `Set`

```js
const tags = ['html', 'css', 'html', 'js', 'css'];
const unique = [...new Set(tags)]; // ['html', 'css', 'js']
```

## Computing Totals with `.reduce()`

```js
const minutes = [6, 8, 9, 12];
const total = minutes.reduce((sum, m) => sum + m, 0); // 35
```

  { track: 'CSS', mins: 10 },

const totalMinutes = lessons.reduce((sum, l) => sum + l.mins, 0);
