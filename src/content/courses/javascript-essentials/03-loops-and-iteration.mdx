Loops let your program repeat work without copy-pasting code. In modern JavaScript, **`for...of`** is the cleanest default for iterating arrays, strings, Maps, and Sets.

## `for...of` vs. Classic `for`

```js
const tracks = ['HTML', 'CSS', 'JavaScript'];

for (const track of tracks) {
  console.log(track);
}
```

Use **`continue`** to skip the current item and move to the next, or **`break`** to exit the loop early (something `.forEach()` cannot do!).

<Callout type="tip" title="Need the Index Too?">
  Use <code>for (const [index, item] of tracks.entries())</code> to get both the index and the value cleanly in a <code>for...of</code> loop.
</Callout>

## Try It Yourself

<Playground
  client:visible
  title="Looping & Early Exit with for...of"
  defaultTab="js"
  showConsole={true}
  height={250}
  html={`<ul id="out"></ul>`}
  css={`ul { padding-left: 20px; font-size: 14px; line-height: 1.7; }`}
  js={`const lessons = ['HTML', 'CSS', 'SKIP:Draft', 'JavaScript', 'STOP', 'Hidden'];
const list = document.querySelector('#out');

for (const [i, item] of lessons.entries()) {
  if (item.startsWith('SKIP:')) continue;
  if (item === 'STOP') break;

  const li = document.createElement('li');
  li.textContent = \`#\${i + 1}: \${item}\`;
  list.appendChild(li);
  console.log('Rendered:', item);
}`}
/>
