Instead of manually stitching raw HTML strings (which risks XSS bugs), modern DOM APIs make creating and updating elements both **safe** and **concise**.

## Everyday DOM Methods

| Method | What It Does |
| :--- | :--- |
| `el.classList.toggle('open')` | Adds class if absent, removes if present |
| `document.createElement('li')` | Creates a fresh element node |
| `parent.replaceChildren(...nodes)` | Replaces all children cleanly in a single DOM update |
| `el.remove()` | Removes the element from the DOM |

<Callout type="tip" title="Second Argument to classList.toggle()">
  Pass a boolean as the second argument (<code>el.classList.toggle('active', isSelected)</code>)to explicitly force-add or force-remove a class without writing an <code>if/else</code>!
</Callout>
