Bugs happen in every codebase. The difference between brittle code and production-grade code is **failing loudly with clear error messages** during development and **recovering gracefully** for end users.

## Throwing Descriptive Errors

```js
function divide(a, b) {
  if (b === 0) {
    throw new Error('Cannot divide by zero');
  }
  return a / b;
}
```

<Callout type="tip" title="Always Throw Error Objects">
  Throw <code>new Error('message')</code> rather than plain strings, an <code>Error</code> object automatically captures a full stack trace showing the exact file and line number.
</Callout>

## Try It Yourself

Test valid JSON vs. malformed JSON below and watch how `try / catch` prevents the app from crashing:

<Playground
  client:visible
  title="Safe JSON Validator with try/catch"
  defaultTab="js"
  showConsole={true}
  height={250}
  html={`<textarea id="jsonInput" rows="3">{ "course": "JS", "free": true }</textarea>
<button id="check">Validate JSON</button>
<p id="result"></p>`}
  css={`textarea { width: 100%; max-width: 360px; padding: 8px; border-radius: 8px; border: 1px solid #cbd5e1; font-family: monospace; font-size: 13px; display: block; margin-bottom: 8px; }
button { background: #2563eb; color: #fff; border: none; border-radius: 8px; padding: 7px 12px; font-weight: 600; cursor: pointer; font-size: 13px; }
#result { margin-top: 10px; font-size: 13px; font-weight: 600; }`}
  js={`const input = document.querySelector('#jsonInput');
const result = document.querySelector('#result');

document.querySelector('#check').addEventListener('click', () => {
  try {
    const parsed = JSON.parse(input.value);
    result.style.color = '#15803d';
    result.textContent = 'Valid JSON! Keys: ' + Object.keys(parsed).join(', ');
    console.log('Parsed OK:', parsed);
  } catch (err) {
    result.style.color = '#b91c1c';
    result.textContent = 'Invalid JSON: ' + err.message;
    console.error(err.message);
  }
});`}
/>
