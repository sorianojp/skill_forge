**`localStorage`** lets your web app remember state across page reloads, with zero backend database! DevPath itself uses `localStorage` to save your completed lessons and theme preference.

## Storing Objects via `JSON`

`localStorage` only stores **strings**. To save an object or array, convert it with `JSON.stringify()` on write and `JSON.parse()` on read:

```js
const prefs = { theme: 'dark', fontSize: 16 };
localStorage.setItem('prefs', JSON.stringify(prefs));

const loaded = JSON.parse(localStorage.getItem('prefs') ?? '{}');
```

<Callout type="warning" title="Never Store Secrets in localStorage">
  Any JavaScript running on the page can read <code>localStorage</code>. It is great for UI preferences, drafts, and learning progress, never for passwords or sensitive auth tokens.
</Callout>

## Try It Yourself

Notice how our safe storage wrapper gracefully handles sandboxed environments where `localStorage` may be restricted, falling back to in-memory storage without crashing:

<Playground
  client:visible
  title="Resilient Note Persistence Wrapper"
  defaultTab="js"
  showConsole={true}
  height={250}
  html={`<div class="box">
  <label for="note"><strong>Scratchpad Note</strong></label>
  <textarea id="note" rows="3" placeholder="Type a note..."></textarea>
  <p id="status" class="status">Ready</p>
</div>`}
  css={`.box { max-width: 360px; display: grid; gap: 8px; }
textarea { padding: 8px; border-radius: 8px; border: 1px solid #cbd5e1; font-family: inherit; font-size: 13px; }
.status { margin: 0; font-size: 12px; color: #15803d; font-weight: 600; }`}
  js={`const KEY = 'demo_note_v1';
const memoryFallback = new Map();

function save(key, value) {
  const json = JSON.stringify(value);
  try { localStorage.setItem(key, json); }
  catch { memoryFallback.set(key, json); }
}

const textarea = document.querySelector('#note');
const status = document.querySelector('#status');

textarea.addEventListener('input', () => {
  const payload = { text: textarea.value, updatedAt: new Date().toLocaleTimeString() };
  save(KEY, payload);
  status.textContent = \`Saved (\${payload.text.length} chars) at \${payload.updatedAt}\`;
  console.log('Saved JSON:', JSON.stringify(payload));
});`}
/>
