These three modern ES syntax features make your code dramatically shorter and safer:

1. **Destructuring**: `const { title, level = 'Beginner' } = course;`
2. **Spread (`...`)**: `const updated = { ...course, completed: true };` (copies without mutating `course`!)
3. **Optional Chaining (`?.`)**: `const city = user?.profile?.address?.city ?? 'Unknown';` (returns `undefined` instead of throwing `TypeError: Cannot read properties of undefined`!)

<Callout type="note" title="Shallow Copy Reminder">
  The spread operator <code>&#123; ...obj &#125;</code> creates a <strong>shallow copy</strong>. For deep cloning nested objects, use the built-in <code>structuredClone(obj)</code>!
</Callout>

<Playground

// 2. Immutable spread update
const nextCourse = { ...course, completed: true };

// 3. Safe optional chaining on missing nested field
const sponsor = course.sponsor?.company?.name ?? 'Community Funded';

const summary = { title, level, completed: nextCourse.completed, sponsor };
document.querySelector('#out').textContent = JSON.stringify(summary, null, 2);
console.log('Original course untouched:', course.completed);`}
