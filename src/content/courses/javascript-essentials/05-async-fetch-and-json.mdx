Fetching data from an API takes time. JavaScript handles slow operations asynchronously using **Promises** so the browser never freezes while waiting.

## Clean `async` / `await` Pattern

```js
async function loadLesson() {
  try {
    const response = await fetch('/api/lesson.json');
    if (!response.ok) throw new Error('Failed to load');
    const data = await response.json();
    return data;
  } catch (err) {
    console.error(err.message);
  }
}
```

<Callout type="warning" title="Always Check response.ok">
  <code>fetch()</code> only rejects on network failures, not HTTP 404 or 500 errors! Always check <code>if (!response.ok) throw new Error(...)</code> before parsing JSON.
</Callout>
