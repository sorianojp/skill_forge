**Functions** let you package reusable logic so you don't repeat yourself. Modern JavaScript favors **arrow functions** (`const fn = (x) => ...`) and **template literals** (backticks `` `Hello, ${name}` ``).

## Clean Arrow Functions

```js
const getGrade = (score) => {
  if (score >= 90) return 'A: Excellent!';
  if (score >= 75) return 'B: Solid work!';
  return 'Keep practicing!';
};
```
