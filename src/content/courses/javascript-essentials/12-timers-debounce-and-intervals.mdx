Timers let you coordinate delayed notifications, countdowns, and performance optimizations like **debouncing**.

## Debouncing Rapid Input

When a user types `"javascript"` into a search bar, firing an API request on all 10 keystrokes wastes bandwidth. A **debounce** waits until the user pauses typing for `300ms`:

```js
function debounce(fn, delayMs = 300) {
  let timerId;
  return (...args) => {
    clearTimeout(timerId);
    timerId = setTimeout(() => fn(...args), delayMs);
  };
}
```

<Callout type="warning" title="Always Clean Up Intervals">
  Save the ID returned by <code>setInterval()</code> and call <code>clearInterval(id)</code> when stopping or unmounting so timers don't leak memory or stack up!
</Callout>
