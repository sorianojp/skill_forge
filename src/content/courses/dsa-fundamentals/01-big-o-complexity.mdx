**Big-O notation** measures how an algorithm's runtime or memory grows as input size `n` increases:

- **`O(1)`**: Array index lookup, Hash Map get/set.
- **`O(log n)`**: Binary search (halves the search space each step).
- **`O(n)`**: Single pass over an array.
- **`O(n log n)`**: Efficient sorting (Merge Sort, Timsort).
- **`O(n^2)`**: Nested loops comparing every pair of items (slow at `n = 100,000`).

<Callout type="tip" title="Drop Constants in Big-O">
  Two sequential loops over <code>n</code> items take <code>2n</code> operations, which simplifies to <code>O(n)</code>. Only a <em>nested</em> loop inside another loop becomes <code>O(n^2)</code>.
</Callout>
