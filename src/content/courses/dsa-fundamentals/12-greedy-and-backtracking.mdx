- **Greedy:** At every step, pick the locally best option (for example, sorting meetings by **earliest end time** to fit the maximum number of non-overlapping meetings).
- **Backtracking:** Explore a decision tree systematically using three lines: **choose** (`path.push(x)`), **explore** (`dfs(i + 1)`), and **unchoose** (`path.pop()`).

<Callout type="tip" title="The 3-Step Backtracking Template">
  Nearly every subsets, permutations, and combinations problem reduces to <code>path.push(choice); recurse(); path.pop();</code>.
</Callout>

## Live DSA Playground

<Playground
  client:visible
  title="Generate All Subsets (Backtracking)"
  defaultTab="js"
  showConsole={true}
  html={`<p>Generate all 2^n subsets of ["Git", "Linux", "Docker"].</p>`}
  js={`function subsets(items) {
  const result = [], path = [];
  function dfs(start) {
    result.push([...path]);
    for (let i = start; i < items.length; i++) {
      path.push(items[i]);
      dfs(i + 1);
      path.pop();
    }
  }
  dfs(0);
  return result;
}

const all = subsets(["Git", "Linux", "Docker"]);
console.log("Total subsets:", all.length);
console.log(all);`}
/>
