A **Binary Heap (Priority Queue)** keeps the minimum (or maximum) element at index `0` (`O(1)` peek) and supports `push` and `pop` in **$O(\log n)$**. Because it is stored in a flat array (`parent = Math.floor((i - 1) / 2)`), it has zero pointer overhead.

<Callout type="tip" title="Top-K Largest Uses a Min-Heap of Size k">
  To find the top 3 scores out of 1,000,000, keep a <strong>Min-Heap</strong> of size 3. Whenever a new score beats the smallest item at the top of the heap, swap it in. Total time: <code>O(n log 3)</code> instead of <code>O(n log n)</code>!
</Callout>

## Live DSA Playground

<Playground
  client:visible
  title="Compact Min-Heap Implementation"
  defaultTab="js"
  showConsole={true}
  html={`<p>Push unsorted priorities and pop them out in ascending order.</p>`}
  js={`class MinHeap {
  data = [];
  push(val) {
    this.data.push(val);
    let i = this.data.length - 1;
    while (i > 0) {
      const p = Math.floor((i - 1) / 2);
      if (this.data[p] <= this.data[i]) break;
      [this.data[p], this.data[i]] = [this.data[i], this.data[p]];
      i = p;
    }
  }
  peek() { return this.data[0]; }
}

const heap = new MinHeap();
[42, 15, 30, 7, 25].forEach((n) => heap.push(n));
console.log("Smallest element (O(1) peek):", heap.peek());
console.log("Heap array:", heap.data);`}
/>
