- **Stack (LIFO - Last In, First Out):** Like a stack of plates. Both `push` and `pop` happen at the top in $O(1)$. Used for function call stacks, undo/redo, and bracket matching.
- **Queue (FIFO - First In, First Out):** Like a checkout line. Used for job scheduling, print queues, and Breadth-First Search (BFS).

<Callout type="info" title="Array.shift() Is O(n)">
  In JavaScript, calling <code>queue.shift()</code> shifts every remaining item left (<code>O(n)</code>). For large BFS queues, track a <code>head</code> index pointer instead so dequeue stays <code>O(1)</code>!
</Callout>

  const stack = [];
  const pairs = { ")": "(", "]": "[", "}": "{" };
  for (const ch of s) {
    if ("([{".includes(ch)) {
      stack.push(ch);
    } else if (pairs[ch]) {
      if (stack.pop() !== pairs[ch]) return false;
    }
  }
  return stack.length === 0;
}

console.log("({[]}) ->", isValidBrackets("({[]})"));
console.log("([)]   ->", isValidBrackets("([)]"));`}
