**Merge Sort** divides an array in half recursively until subarrays have length 1, then merges sorted halves back together in linear time. Unlike Quick Sort (which can degrade to $O(n^2)$ on bad pivots), Merge Sort guarantees **$O(n \log n)$** worst-case time and is **stable** (preserving original relative order for equal keys).

<Callout type="info" title="Built-In Sorts Use Timsort / Introsort">
  Python, Java, and modern JavaScript engines use <strong>Timsort</strong> (a hybrid of Merge Sort + Insertion Sort) which is stable and runs in <code>O(n)</code> on already-sorted data.
</Callout>

  js={`function merge(a, b) {
  const out = [];
  let i = 0, j = 0;
  while (i < a.length && j < b.length) {
    out.push(a[i] <= b[j] ? a[i++] : b[j++]);
  }
  return out.concat(a.slice(i), b.slice(j));
}

function mergeSort(arr) {
  if (arr.length <= 1) return arr;
  const mid = Math.floor(arr.length / 2);
  return merge(mergeSort(arr.slice(0, mid)), mergeSort(arr.slice(mid)));
}

console.log("Sorted:", mergeSort([38, 27, 43, 3, 9, 82, 10]));`}
