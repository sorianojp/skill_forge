**Dynamic Programming (DP)** applies whenever a problem has **optimal substructure** and **overlapping subproblems**. Instead of recomputing `climb(4)` thousands of times, store each answer once (**memoization**) or build answers bottom-up in a simple $O(n)$ loop!

## Capstone Playground

<Playground
  client:visible
  title="O(n) Time, O(1) Space Climbing Stairs DP"
  defaultTab="js"
  showConsole={true}
  html={`<p>Count distinct ways to climb n stairs taking 1 or 2 steps at a time.</p>`}
  js={`function climbStairs(n) {
  if (n <= 1) return 1;
  let prev2 = 1, prev1 = 1;
  for (let i = 2; i <= n; i++) {
    const cur = prev1 + prev2;
    prev2 = prev1;
    prev1 = cur;
  }
  return prev1;
}

for (const n of [3, 5, 10, 30]) {
  console.log("n=" + n + " -> " + climbStairs(n) + " ways");
}`}
/>
