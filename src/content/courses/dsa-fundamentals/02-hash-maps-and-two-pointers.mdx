Whenever you see a brute-force solution checking "is there another element that complements `x`?", a **Hash Map** (`new Map()`) turns the inner $O(n)$ scan into an $O(1)$ lookup, dropping total runtime from $O(n^2)$ to **$O(n)$**.

<Callout type="tip" title="Two Pointers Save Memory on Sorted Arrays">
  When an array is already sorted, placing one pointer at index <code>0</code> and one at <code>n - 1</code> solves pair-sum and palindrome problems in <code>O(n)</code> time and <code>O(1)</code> extra space.
</Callout>

## Live DSA Playground

<Playground
  client:visible
  title="Two Sum in O(n) Time"
  defaultTab="js"
  showConsole={true}
  html={`<p>Check the console for the O(n) Hash Map Two Sum result.</p>`}
  js={`function twoSum(nums, target) {
  const seen = new Map();
  for (let i = 0; i < nums.length; i++) {
    const need = target - nums[i];
    if (seen.has(need)) return [seen.get(need), i];
    seen.set(nums[i], i);
  }
  return [];
}

console.log("Indices for target 9:", twoSum([2, 7, 11, 15], 9));
console.log("Indices for target 18:", twoSum([2, 7, 11, 15], 18));`}
