Whenever a problem asks for the **longest/shortest/maximum contiguous subarray or substring**, avoid recomputing each window from scratch in $O(n^2)$. A **Sliding Window** moves `right` forward to add an element and `left` forward to remove an element, visiting each item at most twice -> **$O(n)$ time**.

<Callout type="tip" title="Fixed vs. Variable Window">
  For a fixed size <code>k</code>, add <code>nums[i]</code> and subtract <code>nums[i - k]</code>. For variable windows (like longest unique substring), shrink <code>left</code> with a <code>while</code> loop until valid again.
</Callout>

## Live DSA Playground

<Playground
  client:visible
  title="Longest Substring Without Repeating Characters"
  defaultTab="js"
  showConsole={true}
  html={`<p>Run the O(n) variable sliding window on sample strings.</p>`}
  js={`function longestUnique(s) {
  const seen = new Set();
  let left = 0, best = 0;
  for (let right = 0; right < s.length; right++) {
    while (seen.has(s[right])) {
      seen.delete(s[left++]);
    }
    seen.add(s[right]);
    best = Math.max(best, right - left + 1);
  }
  return best;
}

console.log("abcabcbb ->", longestUnique("abcabcbb"));
console.log("devpath  ->", longestUnique("devpath"));`}
/>
