**SOLID** is an acronym for five time-tested OOP design principles that keep medium and large codebases easy to test and evolve:

- **S (Single Responsibility):** A class should have one focused reason to change.
- **O (Open/Closed):** Open for extension, closed for modification.
- **L (Liskov Substitution):** Subclasses must honor their parent class's contract without surprising callers.
- **I (Interface Segregation):** Prefer small, focused interfaces over bloated mega-interfaces.
- **D (Dependency Inversion):** Depend on abstractions (injected dependencies), not hardcoded concrete classes.

<Callout type="tip" title="Dependency Injection Makes Testing Effortless">
  When an <code>OrderService</code> receives its repository via its constructor, production can pass <code>PostgresOrderRepo</code> while unit tests pass a fast in-memory fake.
</Callout>

## Try It Yourself (Live OOP Playground)

<Playground
  client:visible
  title="Open/Closed Discount Engine"
  defaultTab="js"
  showConsole={true}
  html={`<p>Add new discount strategies without modifying PriceCalculator.</p>`}
  js={`class PercentDiscount {
  constructor(pct) { this.pct = pct; }
  apply(price) { return price * (1 - this.pct / 100); }
}

class FlatDiscount {
  constructor(amount) { this.amount = amount; }
  apply(price) { return Math.max(0, price - this.amount); }
}

class PriceCalculator {
  constructor(discountStrategy) {
    this.discountStrategy = discountStrategy;
  }
  finalPrice(basePrice) {
    return this.discountStrategy.apply(basePrice);
  }
}

console.log("20% off $100:", new PriceCalculator(new PercentDiscount(20)).finalPrice(100));
console.log("$15 off $100:", new PriceCalculator(new FlatDiscount(15)).finalPrice(100));`}
/>
