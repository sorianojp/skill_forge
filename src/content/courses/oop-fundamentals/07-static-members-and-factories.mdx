A **static method** belongs to the class itself rather than a specific instance (`Money.fromCents(1999)` instead of `new Money(19.99)`). Static factory methods give object creation clear, self-documenting names.

<Callout type="tip" title="Named Factories Beat Ambiguous Constructors">
  <code>Duration.fromMinutes(30)</code> and <code>Duration.fromSeconds(1800)</code> are immediately clear, whereas <code>new Duration(30)</code> forces readers to guess the unit.
</Callout>

## Live OOP Playground

<Playground
  client:visible
  title="Named Static Factories"
  defaultTab="js"
  showConsole={true}
  html={`<p>Inspect how static factories clarify units when creating Duration objects.</p>`}
  js={`class Duration {
  constructor(seconds) {
    this.seconds = seconds;
  }
  static fromMinutes(mins) {
    return new Duration(mins * 60);
  }
  static fromHours(hours) {
    return new Duration(hours * 3600);
  }
  label() {
    return this.seconds + "s";
  }
}

console.log("15m =", Duration.fromMinutes(15).label());
console.log("2h  =", Duration.fromHours(2).label());`}
/>
