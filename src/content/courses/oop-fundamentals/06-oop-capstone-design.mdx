In this capstone, you will combine all four pillars of OOP into a clean, extensible **Library System**:

1. **Encapsulation:** `Book` protects `#checkedOut` so books cannot be double-borrowed.
2. **Polymorphism:** Different `FinePolicy` classes compute late fees differently.
3. **Composition & DI:** `Library` composes a catalog and a `FinePolicy`.

## Capstone Playground

<Playground
  client:visible
  title="Modular OOP Library System"
  defaultTab="js"
  showConsole={true}
  html={`<p>Run and experiment with the Library, Book, and FinePolicy classes.</p>`}
  js={`class Book {
  #checkedOut = false;
  constructor(title) {
    this.title = title;
  }
  borrow() {
    if (this.#checkedOut) return false;
    this.#checkedOut = true;
    return true;
  }
  get available() {
    return !this.#checkedOut;
  }
}

class StandardFinePolicy {
  calculate(daysLate) {
    return daysLate * 0.5;
  }
}

class Library {
  constructor(finePolicy) {
    this.books = [];
    this.finePolicy = finePolicy;
  }
  add(book) { this.books.push(book); }
  report() {
    return this.books.map((b) => b.title + " (" + (b.available ? "Available" : "Borrowed") + ")");
  }
}

const lib = new Library(new StandardFinePolicy());
const b1 = new Book("Design Patterns");
const b2 = new Book("Clean Architecture");
lib.add(b1);
lib.add(b2);
b1.borrow();
console.log(lib.report());
console.log("4 days late fine: $" + lib.finePolicy.calculate(4));`}
/>
