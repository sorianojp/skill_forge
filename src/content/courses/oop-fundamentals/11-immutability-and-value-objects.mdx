A **Value Object** (like `Money(10, "USD")` or `Email("a@b.com")`) has no unique ID; two value objects are equal if their values match. Making value objects **immutable** eliminates subtle side-effect bugs where changing a price in one service silently mutates another object.

<Callout type="tip" title="Make Invalid States Unrepresentable">
  Validate inside the Value Object constructor (for example, rejecting negative amounts or mismatched currencies) so the rest of your codebase never has to re-validate.
</Callout>

## Live OOP Playground

<Playground
  client:visible
  title="Immutable Money Value Object"
  defaultTab="js"
  showConsole={true}
  html={`<p>Adding two Money objects leaves both originals completely unchanged.</p>`}
  js={`class Money {
  constructor(amount, currency) {
    this.amount = amount;
    this.currency = currency;
    Object.freeze(this);
  }
  add(other) {
    if (this.currency !== other.currency) throw new Error("Currency mismatch");
    return new Money(this.amount + other.amount, this.currency);
  }
  equals(other) {
    return this.amount === other.amount && this.currency === other.currency;
  }
}

const a = new Money(25, "USD");
const b = new Money(15, "USD");
const total = a.add(b);
console.log("a:", a.amount, "total:", total.amount, "equals 40?", total.equals(new Money(40, "USD")));`}
/>
