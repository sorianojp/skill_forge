The **Observer pattern** defines a one-to-many notification channel: when a subject emits an event (`lessonCompleted`), every registered listener reacts independently without the emitter knowing who is listening.

<Callout type="tip" title="Always Support Unsubscribe">
  Returning a cleanup function from <code>subscribe()</code> lets UI components detach listeners when unmounted, preventing memory leaks.
</Callout>

## Live OOP Playground

<Playground
  client:visible
  title="Observer Event Channel"
  defaultTab="js"
  showConsole={true}
  html={`<p>Watch multiple subscribers react to a single domain event.</p>`}
  js={`class EventChannel {
  #listeners = new Set();
  subscribe(fn) {
    this.#listeners.add(fn);
    return () => this.#listeners.delete(fn);
  }
  emit(payload) {
    this.#listeners.forEach((fn) => fn(payload));
  }
}

const bus = new EventChannel();
bus.subscribe((e) => console.log("[Badge] Unlocked:", e.lesson));
const off = bus.subscribe((e) => console.log("[Analytics] Tracked:", e.lesson));

bus.emit({ lesson: "Observer Pattern" });
off();
bus.emit({ lesson: "Decorator Pattern" });`}
/>
