Clean OOP pays its biggest dividend during **unit testing**. Because your service accepts its dependencies through the constructor (Dependency Injection), you can pass a 5-line **in-memory fake** instead of spinning up a real database or HTTP server.

## Arrange, Act, Assert (AAA)

1. **Arrange:** Instantiate the fake dependency and the service under test.
2. **Act:** Call the method you want to verify.
3. **Assert:** Check the return value or state stored in the fake.

<Callout type="tip" title="Fakes Beat Brittle Mocks">
  A tiny in-memory fake class (like <code>InMemoryRepo</code> backed by an array or <code>Map</code>) tests real behavior without breaking whenever you refactor internal method calls.
</Callout>

## Live OOP Playground

<Playground
  client:visible
  title="Unit Testing with an In-Memory Fake"
  defaultTab="js"
  showConsole={true}
  html={`<p>Run the mini test suite below to verify RegistrationService.</p>`}
  js={`class InMemoryUserRepo {
  items = [];
  save(email) { this.items.push(email); }
  exists(email) { return this.items.includes(email); }
}

class RegistrationService {
  constructor(repo) { this.repo = repo; }
  register(email) {
    if (this.repo.exists(email)) return false;
    this.repo.save(email);
    return true;
  }
}

// Mini unit test runner
const repo = new InMemoryUserRepo();
const svc = new RegistrationService(repo);
console.log("Test 1 (new user):", svc.register("sam@dev.io") === true ? "PASS" : "FAIL");
console.log("Test 2 (duplicate):", svc.register("sam@dev.io") === false ? "PASS" : "FAIL");`}
/>
