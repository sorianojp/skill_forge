**Object-Oriented Programming (OOP)** organizes software around **objects** that bundle **data (properties/fields)** and **behavior (methods)** together. These concepts transfer directly across Java, C#, C++, Python, PHP, and JavaScript.

## Blueprint vs. Instance

- A **class** defines the structure and behavior (for example, `Course`).
- An **object** is a concrete instance created from that class (`new Course("OOP", 6)`), with its own independent state.

<Callout type="tip" title="One Class, Many Independent Objects">
  Each instance created with <code>new</code> gets its own memory for fields like <code>this.title</code>, while sharing the class's methods cleanly.
</Callout>

## Try It Yourself (Live OOP Playground)

<Playground
  client:visible
  title="Classes & Objects in Action"
  defaultTab="js"
  showConsole={true}
  html={`<p>Check the console output below to inspect your Course objects.</p>`}
  js={`class Course {
  constructor(title, lessons) {
    this.title = title;
    this.lessons = lessons;
    this.completed = 0;
  }

  completeLesson() {
    if (this.completed < this.lessons) {
      this.completed++;
    }
  }

  summary() {
    return this.title + ": " + this.completed + "/" + this.lessons + " lessons";
  }
}

const oop = new Course("OOP Fundamentals", 6);
oop.completeLesson();
oop.completeLesson();
console.log(oop.summary());`}
/>
