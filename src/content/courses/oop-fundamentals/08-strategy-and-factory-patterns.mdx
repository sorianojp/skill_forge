The **Strategy pattern** lets you swap an algorithm (shipping rate, sorting rule, compression codec) at runtime by injecting an object that conforms to a shared contract. A **Factory** maps a configuration key (`"express"`, `"standard"`) to the right concrete strategy.

<Callout type="info" title="Patterns Follow SOLID Naturally">
  Strategy + Factory is the Open/Closed Principle in action: add a new shipping class and register it in the factory without touching checkout code.
</Callout>

<Playground
  client:visible
  title="Shipping Strategy + Factory"
  defaultTab="js"
  showConsole={true}
  html={`<p>Run to see Strategy and Factory work together.</p>`}

  cost(weightKg) { return 4 + weightKg * 1.5; }
}
class ExpressShipping {
  cost(weightKg) { return 12 + weightKg * 3.0; }
}

const ShippingFactory = {
  create(mode) {
    return mode === "express" ? new ExpressShipping() : new StandardShipping();
  }
};

const orderWeight = 2;
console.log("Standard:", "$" + ShippingFactory.create("standard").cost(orderWeight));
console.log("Express: ", "$" + ShippingFactory.create("express").cost(orderWeight));`}
