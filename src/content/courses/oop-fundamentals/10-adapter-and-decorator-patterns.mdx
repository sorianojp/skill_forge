- **Adapter** translates an external or legacy interface into the clean contract your app expects (like a power plug adapter).
- **Decorator** wraps an object implementing the *same* interface to add extra behavior (logging, timing, retries, caching) without modifying the original class.

<Callout type="tip" title="Decorators Beat Subclass Explosion">
  Instead of creating <code>CachedLoggedRetryingHttpClient</code>, compose <code>new CacheDecorator(new LogDecorator(new HttpClient()))</code>.
</Callout>

## Live OOP Playground

<Playground
  client:visible
  title="Composable Caching Decorator"
  defaultTab="js"
  showConsole={true}
  html={`<p>Notice the second fetch hits the cache without calling the base service.</p>`}
  js={`class CourseApi {
  fetch(id) {
    console.log("-> Network fetch for", id);
    return "Course #" + id;
  }
}

class CacheDecorator {
  #cache = new Map();
  constructor(inner) { this.inner = inner; }
  fetch(id) {
    if (this.#cache.has(id)) {
      console.log("-> Cache hit for", id);
      return this.#cache.get(id);
    }
    const result = this.inner.fetch(id);
    this.#cache.set(id, result);
    return result;
  }
}

const api = new CacheDecorator(new CourseApi());
console.log(api.fetch("oop"));
console.log(api.fetch("oop"));`}
/>
