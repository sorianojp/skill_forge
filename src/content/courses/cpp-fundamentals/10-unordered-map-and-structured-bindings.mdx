**`std::unordered_map<K, V>`** provides average $O(1)$ hash-table lookups. With C++17 **structured bindings** (`const auto& [key, value]`), iterating over maps is concise and readable.

<Callout type="info" title="Be Careful with map[key] on Missing Keys">
  Reading <code>counts["missing"]</code> inserts a default-initialized <code>0</code> entry! Use <code>counts.contains(key)</code> (C++20) or <code>counts.find(key)</code> when you only want to check presence.
</Callout>

## Live Code Lab

<CodeLab
  client:visible
  title="maps_demo.cpp"
  language="cpp"
  code={`#include <iostream>
#include <string>
#include <unordered_map>
#include <vector>

int main() {
    std::vector<std::string> tags = {"cpp", "stl", "cpp", "raii"};
    std::unordered_map<std::string, int> counts;
    for (const auto& t : tags) counts[t]++;

    std::cout << "cpp count: " << counts["cpp"] << "\\n";
    std::cout << "has rust? " << (counts.contains("rust") ? "yes" : "no") << "\\n";
    return 0;
}`}
  expectedOutput={`cpp count: 2
has rust? no`}
