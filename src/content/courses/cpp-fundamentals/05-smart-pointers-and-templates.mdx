In Modern C++, you almost never write raw `new` or `delete`. Instead, **`std::unique_ptr<T>`** enforces single ownership of a heap object and automatically deletes it when the pointer leaves scope, with zero runtime overhead compared to a raw pointer.

## Generic Templates

A C++ **template** lets you write one algorithm that compiles to specialized, native machine code for any type `T` (`int`, `double`, `std::string`).

<Callout type="tip" title="Default to std::unique_ptr">
  Use <code>std::make_unique&lt;T&gt;(...)</code> by default. Reach for <code>std::shared_ptr&lt;T&gt;</code> only when multiple owners genuinely share lifetime responsibility.
</Callout>

#include <memory>
#include <string>

template <typename T>
T clamp_val(const T& val, const T& lo, const T& hi) {
    if (val < lo) return lo;
    if (val > hi) return hi;
    return val;
}

struct Task {
    std::string title;
};

int main() {
    auto task = std::make_unique<Task>(Task{"Ship C++ Track"});
    std::cout << task->title << " | Clamped: " << clamp_val(120, 0, 100) << "\\n";
    return 0;
}`}
