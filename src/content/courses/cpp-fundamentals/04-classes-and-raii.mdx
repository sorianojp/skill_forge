**RAII (Resource Acquisition Is Initialization)** is the most important idiom in C++: tie every resource (memory, file handles, mutex locks) to an object's lifetime. The constructor acquires the resource, and the destructor (`~ClassName()`) releases it automatically the instant the object leaves scope, even if an exception is thrown.

## `const` Member Functions

Adding `const` after a method signature (for example, `double balance() const`) promises the compiler that calling the method will not mutate the object, allowing it to be called on `const` references.

<Callout type="tip" title="Always Use Member Initializer Lists">
  Initializing fields after a colon in the constructor (<code>: name_(name), hp_(hp)</code>) constructs them directly instead of default-constructing and then reassigning them.
</Callout>
