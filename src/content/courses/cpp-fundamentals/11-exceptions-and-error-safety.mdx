In C++, the idiom is **"throw by value, catch by const reference"** (`catch (const std::exception& e)`). Catching by reference avoids object slicing and unnecessary copies. Because of RAII, every local `std::vector`, `std::string`, and `std::unique_ptr` is destroyed cleanly when an exception unwinds the stack.

<Callout type="tip" title="Use Standard Exception Types">
  Prefer built-in types from <code>&lt;stdexcept&gt;</code> like <code>std::invalid_argument</code>, <code>std::out_of_range</code>, and <code>std::runtime_error</code> instead of throwing raw strings or ints.
</Callout>

## Live Code Lab

<CodeLab
  client:visible
  title="exceptions.cpp"
  language="cpp"
  code={`#include <iostream>
#include <stdexcept>

double divide(double a, double b) {
    if (b == 0.0) throw std::invalid_argument("Division by zero");
    return a / b;
}

int main() {
    try {
        std::cout << divide(10, 2) << "\\n";
        std::cout << divide(10, 0) << "\\n";
    } catch (const std::exception& e) {
        std::cout << "Caught: " << e.what() << "\\n";
    }
    return 0;
}`}
  expectedOutput={`5
Caught: Division by zero`}
