**Modern C++ (C++17 / C++20)** pairs zero-overhead systems performance with expressive high-level abstractions like `std::string`, `std::vector`, and automatic resource cleanup.

## Modern Habits From Day One

- Use `std::string` instead of raw C-style `char[]` strings.
- Prefer `const` or `constexpr` for values that should not change.
- Use `auto` when the right-hand type is obvious or verbose (like iterators).

<Callout type="tip" title="Avoid using namespace std; in Headers">
  Writing <code>std::cout</code> and <code>std::string</code> explicitly prevents subtle name collisions in larger C++ projects.
</Callout>
