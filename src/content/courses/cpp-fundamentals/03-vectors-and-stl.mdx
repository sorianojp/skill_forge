The **Standard Template Library (STL)** is C++'s superpower. `std::vector<T>` stores elements contiguously in memory (just as fast as a raw C array), while automatically resizing and freeing its own memory.

## Range-Based `for` + `<algorithm>`

Combining range-based `for (const auto& x : items)` with algorithms like `std::sort`, `std::count_if`, and lambdas (`[](int n) { return n >= 80; }`) eliminates off-by-one loop bugs.

<Callout type="info" title="Prefer std::vector by Default">
  Because <code>std::vector</code> keeps elements contiguous in CPU cache, it outperforms linked lists (<code>std::list</code>) in almost every real-world workload.
</Callout>

## Interactive Code Lab

<CodeLab
  client:visible
  title="stl_vector.cpp"
  language="cpp"
  code={`#include <algorithm>
#include <iostream>
#include <vector>

int main() {
    std::vector<int> scores = {72, 95, 84, 91};
    scores.push_back(88);

    std::sort(scores.begin(), scores.end());
    auto passing = std::count_if(scores.begin(), scores.end(), [](int s) {
        return s >= 85;
    });

    std::cout << "Lowest: " << scores.front() << " | Highest: " << scores.back() << "\\n";
    std::cout << "Scores >= 85: " << passing << "\\n";
    return 0;
}`}
