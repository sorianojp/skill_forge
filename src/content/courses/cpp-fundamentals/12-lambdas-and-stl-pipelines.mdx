C++ **lambdas** (`[capture](params) { body }`) compile into zero-overhead inline function objects. Pairing lambdas with `<algorithm>` and `<numeric>` (`std::sort`, `std::accumulate`, `std::all_of`) lets you express complex data transformations without hand-written index loops.

<Callout type="tip" title="Capture Explicitly">
  Capture only what you need: <code>[threshold]</code> captures by value, <code>[&amp;total]</code> captures by reference. Explicit captures prevent accidental dangling references.
</Callout>

## Live Code Lab

<CodeLab
  client:visible
  title="lambdas_stl.cpp"
  language="cpp"
  code={`#include <algorithm>
#include <iostream>
#include <numeric>
#include <vector>

int main() {
    std::vector<int> scores = {75, 92, 88, 95};
    int threshold = 85;

    int sum = std::accumulate(scores.begin(), scores.end(), 0);
    auto top = std::count_if(scores.begin(), scores.end(), [threshold](int s) {
        return s >= threshold;
    });

    std::cout << "Sum: " << sum << " | >= " << threshold << ": " << top << "\\n";
    return 0;
}`}
  expectedOutput={`Sum: 350 | >= 85: 3`}
/>
