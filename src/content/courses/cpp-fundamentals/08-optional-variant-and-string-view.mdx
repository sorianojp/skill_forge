- **`std::optional<T>`** represents a value that may or may not be present (`std::nullopt`), replacing fragile sentinel values like `-1`.
- **`std::string_view`** is a lightweight non-owning view (`pointer + length`) over any `std::string` or string literal with zero heap allocation.

<Callout type="warning" title="Never Return a string_view to a Local String">
  Because <code>std::string_view</code> does not own memory, returning a view to a local <code>std::string</code> creates a dangling reference. Use <code>string_view</code> primarily for read-only function parameters.
</Callout>

<CodeLab
  client:visible
  title="optional_view.cpp"
  language="cpp"
  code={`#include <iostream>
#include <optional>
#include <string_view>

std::optional<int> parse_tier(std::string_view label) {
    if (label == "gold") return 1;
    if (label == "silver") return 2;
    return std::nullopt;
}

int main() {
    auto t1 = parse_tier("gold");
    auto t2 = parse_tier("unknown");
    std::cout << "gold=" << t1.value_or(99) << " unknown=" << t2.value_or(99) << "\\n";
    return 0;
}`}
  expectedOutput={`gold=1 unknown=99`}
