In C++, methods are **non-virtual by default** for zero-overhead speed. To enable runtime polymorphism through base pointers (`std::unique_ptr<Shape>`), mark base methods `virtual`, pure interface methods `= 0`, and derived implementations **`override`**.

<Callout type="warning" title="Always Add virtual ~Base() = default;">
  If you delete a derived object through a base class pointer without a <code>virtual</code> destructor, C++ triggers undefined behavior and skips the derived destructor.
</Callout>

## Live Code Lab

<CodeLab
  client:visible
  title="polymorphism.cpp"
  language="cpp"
  code={`#include <iostream>
#include <memory>
#include <vector>

struct Shape {
    virtual ~Shape() = default;
    virtual double area() const = 0;
};

struct Rect : Shape {
    double w, h;
    Rect(double w, double h) : w(w), h(h) {}
    double area() const override { return w * h; }
};

int main() {
    std::vector<std::unique_ptr<Shape>> shapes;
    shapes.push_back(std::make_unique<Rect>(4.0, 5.0));
    std::cout << "Area: " << shapes[0]->area() << "\\n";
    return 0;
}`}
  expectedOutput={`Area: 20`}
/>
