A **reference** (`int& ref = x;`) is an alias for an existing variable. Unlike a pointer, a reference cannot be `nullptr` and cannot be reseated to point somewhere else, making it much safer for everyday function parameters.

## Parameter Passing Cheat Sheet

- Small primitives (`int`, `double`, `bool`): pass **by value** (`int n`).
- Read-only objects (`std::string`, `std::vector`): pass **by const reference** (`const std::string& name`).
- In-place mutation: pass **by non-const reference** (`int& counter`).

<Callout type="tip" title="Zero-Copy Reads with const&">
  Passing a 10MB <code>std::vector</code> by value copies all 10MB. Passing it as <code>const std::vector&lt;int&gt;&amp;</code> costs a single pointer-sized word with full read safety.
</Callout>
