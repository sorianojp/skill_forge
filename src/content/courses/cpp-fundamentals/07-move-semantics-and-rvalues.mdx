Copying a `std::vector` with 1 million elements allocates and copies 1 million items. **Moving** it with **`std::move()`** simply transfers ownership of the underlying heap pointer in $O(1)$ time with zero allocations.

<Callout type="tip" title="Do Not Use std::move on Return Statements">
  Returning a local variable directly (<code>return vec;</code>) allows the compiler to apply Return Value Optimization (NRVO), which is even faster than <code>return std::move(vec);</code>.
</Callout>
