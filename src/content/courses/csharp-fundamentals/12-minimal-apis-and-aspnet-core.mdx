**ASP.NET Core Minimal APIs** let you stand up production-grade HTTP endpoints in a few lines of C# without controller ceremony. Route parameters (`"/courses/{slug}"`), JSON bodies, and DI services are bound automatically as lambda parameters.

<Callout type="tip" title="Return TypedResults in Production">
  Using <code>Results.Ok(data)</code> or <code>Results.NotFound()</code> makes HTTP status codes explicit and automatically generates OpenAPI/Swagger documentation.
</Callout>

## Live Code Lab

<CodeLab
  client:visible
  title="MinimalRouterSim.cs"
  language="csharp"
  code={`using System.Text.Json;

public record ApiResponse(int Status, object Body);

var routes = new Dictionary<string, Func<ApiResponse>>
{
    ["/api/health"] = () => new(200, new { ok = true, runtime = ".NET 8" }),
    ["/api/tracks"] = () => new(200, new { count = 12 })
};

foreach (var path in new[] { "/api/health", "/api/missing" })
{
    var res = routes.TryGetValue(path, out var handler)
        ? handler()
        : new ApiResponse(404, new { error = "Not found" });
    Console.WriteLine($"{path} -> {res.Status} {JsonSerializer.Serialize(res.Body)}");
}`}
  expectedOutput={`/api/health -> 200 {"ok":true,"runtime":".NET 8"}
/api/missing -> 404 {"error":"Not found"}`}
/>
