Accessing `dict["missing"]` in C# throws a `KeyNotFoundException`. The idiomatic, single-lookup pattern is **`if (dict.TryGetValue(key, out var value))`**, which checks existence and extracts the value in one hash lookup.

<Callout type="tip" title="TryGetValue Does One Hash Lookup Instead of Two">
  Writing <code>ContainsKey(k)</code> followed by <code>dict[k]</code> hashes the key twice. <code>TryGetValue(k, out var val)</code> does it in one step.
</Callout>
