**LINQ (Language Integrated Query)** is one of C#'s signature features. It brings SQL-like querying (`Where`, `Select`, `OrderBy`, `GroupBy`, `Sum`) directly into C# with full compile-time type safety and autocomplete.

## Deferred Execution

LINQ queries like `items.Where(...)` are **lazy**: they do not execute until you iterate over them (with `foreach`) or materialize them with `.ToList()`, `.Count()`, or `.Sum()`.

<Callout type="tip" title="Method Syntax Is the Everyday Standard">
  Chaining <code>.Where(x =&gt; ...).OrderBy(x =&gt; ...).Select(x =&gt; ...)</code> composes cleanly and works identically for in-memory lists and Entity Framework Core SQL queries.
</Callout>

## Interactive Code Lab

<CodeLab
  client:visible
  title="LinqDemo.cs"
  language="csharp"
  code={`using System.Linq;

record Course(string Name, int Hours);

var courses = new List<Course>
{
    new("Git", 4),
    new("OOP", 5),
    new("C#", 6),
    new("Java", 6)
};

var names = courses
    .Where(c => c.Hours >= 5)
    .OrderBy(c => c.Name)
    .Select(c => c.Name);

Console.WriteLine(string.Join(", ", names));
Console.WriteLine($"Total hours: {courses.Sum(c => c.Hours)}");`}
  expectedOutput={`C#, Java, OOP
Total hours: 21`}
/>
