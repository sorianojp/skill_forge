Modern .NET servers handle thousands of concurrent requests because **`async` / `await`** releases the worker thread while waiting on database queries, HTTP calls, or disk I/O.

## Golden Rules of Async C#

1. Return `Task` (void-like) or `Task<T>` (value-returning); avoid `async void` except for UI event handlers.
2. Never block on tasks with `.Result` or `.Wait()` (this can deadlock). Always `await` instead.
3. Use `await Task.WhenAll(t1, t2)` to run independent async calls in parallel.

<Callout type="warning" title="Avoid .Result and .Wait()">
  Calling <code>task.Result</code> synchronously blocks a thread pool worker and can cause deadlocks in ASP.NET or UI apps. Propagate <code>async</code> / <code>await</code> all the way up.
</Callout>

    FetchCountAsync("Courses", 12),
    FetchCountAsync("Lessons", 120)
