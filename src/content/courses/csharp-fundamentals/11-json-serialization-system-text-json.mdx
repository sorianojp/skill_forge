**`System.Text.Json`** is built directly into .NET and powers ASP.NET Core's JSON APIs with low memory allocation. It works seamlessly with C# `record` types and supports camelCase serialization out of the box.

<Callout type="tip" title="Reuse JsonSerializerOptions Instances">
  Create a single <code>static readonly JsonSerializerOptions</code> instance and reuse it across requests so .NET caches reflection metadata instead of rebuilding it every call.
</Callout>

## Live Code Lab

<CodeLab
  client:visible
  title="JsonDemo.cs"
  language="csharp"
  code={`using System.Text.Json;

public record CourseDto(string Slug, int Lessons);

var opts = new JsonSerializerOptions { PropertyNamingPolicy = JsonNamingPolicy.CamelCase };
var json = JsonSerializer.Serialize(new CourseDto("csharp-fundamentals", 12), opts);
Console.WriteLine("JSON: " + json);

var parsed = JsonSerializer.Deserialize<CourseDto>(json, opts);
Console.WriteLine($"Parsed: {parsed?.Slug} ({parsed?.Lessons} lessons)");`}
  expectedOutput={`JSON: {"slug":"csharp-fundamentals","lessons":12}
Parsed: csharp-fundamentals (12 lessons)`}
/>
