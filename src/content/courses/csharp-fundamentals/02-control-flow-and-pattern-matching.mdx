C#'s **pattern matching** turns nested `if / else if` chains into concise, readable expressions. You can match exact values, types, properties, and numeric ranges (`>= 90`, `>= 80 and < 90`) directly inside a `switch` expression.

<Callout type="info" title="The Discard Pattern (_)">
  In a C# switch expression, <code>_ =&gt; ...</code> acts as the catch-all default arm so every possible input produces a value.
</Callout>

## Interactive Code Lab

<CodeLab
  client:visible
  title="PatternMatching.cs"
  language="csharp"
  code={`static string Classify(int score) => score switch
{
    >= 90 => "Distinction",
    >= 80 => "Pass",
    >= 60 => "Review",
    _ => "Retry"
};

int[] scores = [96, 84, 70];
foreach (int s in scores)
{
    Console.WriteLine($"{s}: {Classify(s)}");
}`}
  expectedOutput={`96: Distinction
84: Pass
70: Review`}
