Unlike Java's type erasure, **.NET reifies generics at runtime**, meaning `List<int>` stores raw unboxed 32-bit integers with zero heap allocation per element. Use **`where T : ...`** to constrain `T` to types that implement a required interface.

<Callout type="info" title="Generic Result<T> Pattern">
  Returning a generic <code>Result&lt;T&gt;</code> record makes expected failures explicit without throwing exceptions for normal control flow.
</Callout>

## Live Code Lab

<CodeLab
  client:visible
  title="GenericsDemo.cs"
  language="csharp"
  code={`public record Result<T>(bool Ok, T? Value, string? Error);

static T MaxOf<T>(T a, T b) where T : IComparable<T>
    => a.CompareTo(b) >= 0 ? a : b;

var res = new Result<int>(true, MaxOf(42, 99), null);
Console.WriteLine($"Ok={res.Ok}, Max={res.Value}");`}
  expectedOutput={`Ok=True, Max=99`}
