In C#, **properties** (`public decimal Balance { get; private set; }`) give you clean field-like access syntax while keeping full encapsulation. For immutable data models, **`record`** adds built-in value equality and non-destructive copying via **`with`**.

<Callout type="tip" title="Non-Destructive Mutation with 'with'">
  <code>var updated = user with &#123; Score = 95 &#125;;</code> creates a new record copy with only <code>Score</code> changed, leaving the original untouched.
</Callout>
