**C#** is a modern, strongly typed language built for **.NET** web APIs (ASP.NET Core), desktop/mobile apps, cloud services, and Unity game development.

## Modern C# Ergonomics

- **String interpolation:** `$"Track: {track}"` embeds expressions directly inside strings.
- **Nullable annotations:** `string? nickname = null;` tells the compiler a variable may be null, and `nickname ?? "Guest"` provides a clean fallback.

<Callout type="tip" title="String Equality with == in C#">
  Unlike Java, C#'s <code>==</code> operator on <code>string</code> compares text values directly, not memory references.
</Callout>
