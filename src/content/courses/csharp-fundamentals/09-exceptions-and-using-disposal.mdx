In C#, any type that holds unmanaged resources (files, DB connections, HTTP clients) implements **`IDisposable`**. Prefixing the variable with **`using var`** guarantees `Dispose()` is called automatically at the end of the enclosing scope, even if an exception occurs.

<Callout type="warning" title="Rethrow with bare throw;">
  When rethrowing an exception inside a <code>catch</code> block, write <code>throw;</code> (not <code>throw ex;</code>) so .NET preserves the original stack trace.
</Callout>
