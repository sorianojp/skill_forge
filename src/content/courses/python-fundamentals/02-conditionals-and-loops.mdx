In Python, **indentation (4 spaces)** defines code blocks. That keeps every Python file clean and uniform.

## `if` / `elif` / `else`

```python
score = 88
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
else:
    grade = "Keep practicing"
```

<Callout type="tip" title="Use enumerate() for Indexes">
  Instead of manually tracking a counter variable, write <code>for idx, item in enumerate(items, start=1):</code> to get clean 1-based numbering!
</Callout>
