## Try It Yourself

<PythonPlayground
  client:visible
  title="Safe Parsing with try / except"
  code={`def parse_score(raw):
    val = int(raw)
    if not (0 <= val <= 100):
        raise ValueError("Score must be between 0 and 100")
    return val

for sample in ["95", "120", "oops"]:
    try:
        print(sample, "-> valid:", parse_score(sample))
    except ValueError as err:
        print(sample, "-> rejected:", err)`}
/>
