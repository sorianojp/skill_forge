**List comprehensions** are one of Python's signature superpowers. They replace multi-line `for` + `.append()` loops with one clear expression:

```python
scores = [65, 88, 92, 74, 95]
passing = [s for s in scores if s >= 80]
# [88, 92, 95]
```

<Callout type="tip" title="Keep Comprehensions Readable">
  If a comprehension needs more than one condition or nested loop, a regular <code>for</code> loop is usually clearer for teammates to read.
</Callout>
