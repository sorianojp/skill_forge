Writing repetitive `__init__` and `__repr__` boilerplate is a thing of the past. Python's standard-library **`@dataclass`** decorator generates them automatically from typed fields!

<Callout type="tip" title="Immutable Dataclasses">
  Pass <code>@dataclass(frozen=True)</code> when you want a read-only data record that can even be stored inside a <code>set</code> or used as a dictionary key.
</Callout>

## Try It Yourself

<PythonPlayground
  client:visible
  title="Clean Python @dataclass"
  code={`from dataclasses import dataclass

@dataclass
class Course:
    title: str
    lessons: int
    completed: int = 0

    def percent(self) -> int:
        return round((self.completed / self.lessons) * 100)

py = Course(title="Python 3 Fundamentals", lessons=12, completed=9)
print(py)
print(f"Progress: {py.percent()}%")`}
