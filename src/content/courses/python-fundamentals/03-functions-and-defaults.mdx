Functions in Python start with the `def` keyword and return values with `return`.

```python
def calculate_percent(done, total, decimals=0):
    ratio = (done / total) * 100
    return round(ratio, decimals)
```

<Callout type="warning" title="Avoid Mutable Default Arguments">
  Never use an empty list <code>def add(item, items=[]):</code> as a default argument in Python, because that list is shared across every call. Use <code>items=None</code> and create a fresh list inside the function.
</Callout>
