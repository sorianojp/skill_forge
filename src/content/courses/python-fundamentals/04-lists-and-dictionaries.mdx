**Lists** (`[1, 2, 3]`) hold ordered sequences, while **Dictionaries** (`{"track": "Python", "free": True}`) store fast key-value mappings.

## Safe Dictionary Lookups with `.get()`

Accessing `course["price"]` raises a `KeyError` if `"price"` does not exist. Calling `course.get("price", 0)` safely returns `0` instead!

<Callout type="tip" title="Negative Indexing & Slicing">
  In Python, <code>items[-1]</code> grabs the last element, and <code>items[:3]</code> slices the first 3 elements cleanly.
</Callout>
