Python is famous for its clean, readable syntax. You do not need semicolons or curly braces; Python uses indentation and clear keywords.

## Core Data Types

- **`str`**: Text inside quotes, like `"DevPath"`
- **`int`**: Whole numbers, like `42`
- **`float`**: Decimal numbers, like `3.14`
- **`bool`**: `True` or `False` (capitalized in Python!)

## Formatting with f-Strings

Prefix a string with `f` and place expressions inside `{ ... }`:

```python
name = "Ada"
lessons = 6
print(f"Welcome, {name}! You have {lessons} Python lessons.")
```

<Callout type="tip" title="Naming Convention">
  Python uses <code>snake_case</code> for variables and functions (for example, <code>total_score</code> instead of <code>totalScore</code>).
</Callout>
