# skill_forge

**SkillForge** is a free, interactive web development learning platform built with Astro, React islands, MDX, Tailwind CSS v4, CodeMirror 6, and Pagefind.

## Features
- **48 Interactive Lessons** across Modern HTML Fundamentals, Modern CSS & Layout, and Modern JavaScript & the DOM
- **Try It Yourself Playgrounds** (HTML/CSS/JS live editor + sandboxed iframe preview + Console)
- **Inline Quizzes, Fill-in-the-Blank Exercises & Auto-Graded Capstone Challenges**
- **Course Final Exams & Free Downloadable Certificates** (PNG, SVG, Print/PDF)
- **No-Login Local Progress Tracking** + `/progress` My Learning dashboard
- **Instant Full-Text Search** (`⌘K`) powered by Pagefind

## Local Development
```bash
npm install
npm run dev
```

## Production Build & Preview
```bash
npm run build
npm run preview
```
